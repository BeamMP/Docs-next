# Spieldokumentation

BeamMP läuft innerhalb von BeamNG.drive, daher ist vieles von dem, was du für BeamMP schreibst, eigentlich BeamNG.drive-Code. In diesem Bereich findest du Anleitungen und Snippets für diesen Code. Die [Dokumentation](https://documentation.beamng.com/) von BeamNG ist die vollständige Referenz.

Die Funktionen und Events von BeamMP selbst findest du in den [Scripting-Referenzen](/de/developers/beammp-scripting/).

## Anleitungen

- [Inhaltsentwicklung](/de/game-documentation/content-development/): wo du lernst, wie man Karten, Objekte und Fahrzeuge erstellt.
- [UI-Apps (HTML)](/de/game-documentation/programming/ui-apps-html-cef): erstelle eine App, die auf dem Bildschirm des Spiels angezeigt wird.
- [ImGui-Fenster-Tutorial](/de/game-documentation/programming/imgui): erstelle ein einfaches ImGui-Fenster.
