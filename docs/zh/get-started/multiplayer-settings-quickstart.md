# 首次多人模式设置

BeamMP 有自己的多人模式设置。你不需要修改其中任何一项就能游玩。下面这些是第一次游玩时值得了解的设置。每一项设置的详细说明都在[多人模式设置](/zh/players/multiplayer-settings)中。

## 查看所有设置

开启 **显示高级选项** 即可看到所有多人模式设置。关闭时，你只会看到基本设置。

## 你可能想要修改的设置

| 设置 | 作用 | 何时修改 |
|---|---|---|
| **新聊天菜单** | 将游戏内聊天显示在一个可以拖出游戏的窗口中，例如拖到另一台显示器上 | 你想把聊天放在第二块屏幕上 |
| **启用车辆位置平滑** | 将其他玩家车辆的移动平滑到固定的时间间隔 | 有玩家的延迟较高，或你的连接经常丢包 |
| **可用时使用简化车辆** | 在有简化版本时，用简化版本替换其他玩家的车辆 | 你更喜欢简化版本，而不是完整模型 |
| **跳过模组安全警告弹窗** | 隐藏连接到带有模组的服务器时显示的警告 | 你经常连接同样的服务器 |
| **隐藏玩家的名称标签** | 不再绘制昵称标签 | 昵称标签碍事 |
| **启用玩家车辆更新/编辑排队处理** | 将其他玩家的车辆刷出和编辑放入队列，而不是立即加载 | 你希望由自己决定车辆何时出现；参见[事件队列](/zh/players/multiplayer-settings#event-queue) |

## 建议保持默认的设置

- **禁用因不稳定导致的暂停**最好保持关闭。反复出现的不稳定可能会导致游戏崩溃。
- **在控制台显示网络活动**会把所有内容写入日志文件，几分钟内日志就可能增长数百兆字节。
- **启动器端口：**只有在无法使用 4444 端口时才需要修改。如果你修改了它，也要在 `Launcher.cfg` 中同步修改。参见[更改启动器端口](/zh/troubleshooting/launcher-port)。
