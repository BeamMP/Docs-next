# Game FAQ

Common questions about playing BeamMP. For account, Patreon and early access questions, see the [Player FAQ](/en/players/faq).

## Playing

### How do I install BeamMP?

Follow [Install BeamMP](/en/get-started/install-beammp). It covers Windows and Linux.

### Does BeamMP work with pirated or modified versions of BeamNG.drive?

BeamMP does not work with pirated or outdated versions of BeamNG.drive.

Modifications, including third-party mods, can interfere with BeamMP. See [Mod Safety](/en/players/mod-safety) for how to remove them.

The BeamMP support team cannot help with problems on pirated, outdated or otherwise modified versions of BeamNG.drive.

### Does BeamMP work on Linux?

The client is not officially supported on Linux. You can follow our guide to [install BeamMP on Linux](/en/get-started/install-beammp#install-on-linux).

### Why does my antivirus or Windows Defender flag the Launcher?

Some antivirus programs flag BeamMP as a threat because it uses the network, among other things. There are **no viruses** in any of the code. The code for the Launcher, the server and the Lua client is on our [GitHub](https://github.com/BeamMP). If you need to allow the Launcher, see [Defender / Firewall Exclusions](/en/troubleshooting/defender-exclusions).

### My performance is poor. What should I do?

We are working to make multiplayer as stable as possible. If you have already lowered your graphics settings and performance is still poor, try a server with fewer players.

The game is mostly limited by the CPU when many people play, so older CPUs, even quad-cores, struggle with more than a handful of players. A general rule of thumb is one car per CPU thread.
