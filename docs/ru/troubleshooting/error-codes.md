# Коды ошибок

На этой странице перечислены коды ошибок и сообщения, которые может показать лаунчер, и что делать в каждом случае. Об ошибках в окне сервера см. [Коды ошибок сервера](/ru/server-owners/error-codes).


| Код | Описание | Возможное решение |
|---|---|---|
| 10048 | Порт лаунчера уже занят чем-то другим | Убедитесь, что одновременно запущен только ОДИН экземпляр BeamMP-Launcher. Попробуйте перезагрузить ПК. |
| 10038 / 10060 / 10061 | Ни один сервер не ответил по указанному IP-адресу и / или порту | Если вы владелец сервера, проверьте переадресацию портов и / или правила брандмауэра, описанные на странице [Запуск сервера](/ru/server-owners/host-a-server). Если вы не владелец сервера, выберите другой сервер или свяжитесь с владельцем, если он вам известен. |
| 10054 | Соединение сброшено удалённой стороной | Сервер, к которому вы подключаетесь, отключился. |
| Failed to find the game please launch it. Report this if the issue persists code 3. | Лаунчеру не удалось найти информацию об игре (папку игры, папку профиля, версию и т. д.) в записи реестра | Запустите игру хотя бы один раз, чтобы создались значения реестра. |
| Failed to find the game please launch it. Report this if the issue persists code 4. | Лаунчеру не удалось прочитать информацию об игре (папку игры, папку профиля, версию и т. д.) в записи реестра | Эта ошибка чаще всего появляется у пользователей с **пиратскими копиями** игры. Если вы купили игру, запустите её хотя бы один раз, чтобы создались значения реестра. |
| Failed to Launch the game! launcher closing soon | Лаунчеру не удалось найти исполняемый файл игры | Запустите игру хотя бы один раз, прежде чем снова запускать лаунчер. |
| Game Closed! launcher closing soon | Игра была закрыта | Это сообщение появляется при закрытии игры или если игра не смогла запуститься. |
| Launcher Update failed! | Лаунчеру не удалось скачать новую версию | Проверьте подключение к интернету и правила брандмауэра / антивируса, чтобы лаунчер не блокировался. |
| Logger file init failed | У лаунчера нет возможности создавать файлы | Запустите лаунчер от имени администратора. |
| Please close the game and try again | Игра уже открыта, и лаунчер не может очистить папку `multiplayer/mods` | Закройте игру и повторите попытку. |
| Please launch the game at least once | Лаунчеру не удалось изменить папку игры | Запустите игру хотя бы один раз, прежде чем снова запускать лаунчер. |
| Primary Servers Offline! Sorry for the inconvenience! | Лаунчеру не удалось проверить наличие обновления | Проверьте подключение к интернету и правила брандмауэра. Если с вашей стороны проблем нет, загляните в [канал обновлений BeamMP](<https://discord.com/channels/601558901657305098/697596153943949352>) на нашем сервере Discord. |
| Sorry Backend System Outage! Don't worry it will back on soon! | Бэкенд BeamMP не ответил | Проверьте подключение к интернету и правила брандмауэра. Если с вашей стороны проблем нет, загляните в [канал обновлений BeamMP](<https://discord.com/channels/601558901657305098/697596153943949352>) на нашем сервере Discord. |
| Stuck on updating | Лаунчер завис на обновлении и не переходит к следующему шагу | Запустите лаунчер от имени администратора и проверьте правила антивируса, чтобы лаунчер не блокировался. |

Если лаунчер сразу закрывается, проверьте файл `Launcher.log` в папке, куда вы установили BeamMP.
