## Get an AuthKey

The AuthKey, also called "Authentication Key", is what makes a **public** server appear in the server list. It is also recommended for private servers.

- You have a limited number of keys. One key works on one server at a time, so you cannot run two servers with the same key.
- You can get more keys by supporting the project. See [How do I get early access?](/en/players/faq) in the Player FAQ.
- You need a [Discord](https://discord.com) account for this. It prevents spam.

::: warning
Never share your AuthKey or show it to anyone. Treat it like a password.
:::

1. Sign in to the [Keymaster](https://keymaster.beammp.com) with Discord, then click **Keys** on the left of the screen.

   ![The Keymaster home page, with Keys in the menu on the left](../../assets/content/keymaster_homepage.png)

2. Click the green **+** button in the top right.

   ![The Keys page with the green plus button in the top right](../../assets/content/keymaster_new_key.png)

3. Fill in the **Server Name** field and click **Create**. This is only the name of the key, not the name your server shows in the server list. For example:

   ![The new key form with a server name filled in](../../assets/content/keymaster_server_name.png)

   The key then looks something like this:

   ![The finished key in the list of keys](../../assets/content/keymaster_key_done.png)

4. Copy the text in the **Key** field by clicking the clipboard icon on the right of the key. In this example the key is `3173a2e-6az0-4542-a3p0-ddqq5ff95558`. Keep it for the next step.

   ![The clipboard icon next to the key](../../assets/content/keymaster_copy_key.png)
