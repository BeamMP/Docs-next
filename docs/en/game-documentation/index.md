# Game Documentation

BeamMP runs inside BeamNG.drive, so much of what you write for BeamMP is really BeamNG.drive code. This section has guides and snippets for that code. BeamNG's own [documentation](https://documentation.beamng.com/) is the full reference.

For BeamMP's own functions and events, see the [scripting references](/en/developers/beammp-scripting/).

## Guides

- [Content Development](/en/game-documentation/content-development/): where to learn about creating maps, props and vehicles.
- [UI Apps (HTML)](/en/game-documentation/programming/ui-apps-html-cef): make an app that shows on the game's screen.
- [ImGui Window Tutorial](/en/game-documentation/programming/imgui): create a basic ImGui window.
