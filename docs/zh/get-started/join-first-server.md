# 加入你的第一个服务器

你已经[安装了 BeamMP](/zh/get-started/install-beammp)。现在启动启动器并连接到服务器。

## 启动多人模式

1. 启动 BeamMP 启动器。会弹出一个终端窗口。启动器会下载 BeamMP 模组、启用它并启动 BeamNG.drive。请勿关闭终端窗口：你游玩期间，启动器必须保持打开。你关闭游戏时，启动器也会随之关闭。
2. 在 BeamNG.drive 主菜单中点击 **模组资源库**，然后打开 **模组管理器** 选项卡，确认 `multiplayerbeammp` 是 **已启用模组** 下唯一的条目。
3. 返回主菜单，点击 **更多……**，然后点击 **BeamMP**。
4. 使用你的 [BeamMP 账号](/zh/players/account)登录，或以访客身份游玩。并非所有服务器都允许访客。启动器通过其文件夹中一个名为 `key` 的文件让你保持登录状态。请不要分享这个文件。
5. 选择一个服务器，然后点击 **Connect**。

::: info 加入可能需要一些时间
当你加载到一张已经刷出了大量车辆的地图时，加入所需的时间可能比你预期的更长。
:::

## 如果无法连接

- **在 更多…… 下没有 BeamMP 条目。** 请确认 BeamMP 模组存在，并已在 **模组管理器** 中启用，然后按 `Ctrl` + `L`。
- **开启了 VPN。** 任何类型的 VPN 都可能导致连接问题。请将其关闭后重试。
- **启动器显示错误。** 请在[错误代码](/zh/troubleshooting/error-codes)或[论坛常见问题](https://forum.beammp.com/c/faq/35)中查找。
- **在 Linux 上，第二次加入失败。** 离开一个服务器后，启动器可能无法连接到下一个服务器，并显示 `(Proxy) bind failed with error: 98` 或 `Connection still alive terminating`。请关闭游戏和启动器，然后重新启动它们。

如需更多帮助，请参阅[故障排除](/zh/troubleshooting/)，或在[论坛](https://forum.beammp.com)或 [Discord 服务器](https://discord.gg/beammp)上提问。
