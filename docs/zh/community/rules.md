# BeamMP 社区规则

::: info
BeamMP 工作人员不必严格按照这些规则进行管理，可以自行酌情处理。除这些规则外，Discord 的[社区准则](https://discord.com/guidelines/)和[服务条款](https://discord.com/terms/)同样适用，并会被执行。
:::

## BeamMP 通用规则（适用于 Discord、论坛和游戏内）

1. 禁止歧视（例如性别歧视、种族主义等） <span class="info-tooltip" title="这包括使用种族或性别方面的侮辱性词语，或其他用来针对个人或群体的词汇，无论是直接使用，还是有意为之。">ⓘ</span>
2. 禁止欺凌或骚扰 <span class="info-tooltip" title="这包括通过不受欢迎的行为、未经请求的私信（DM），或通过消息、图片或语言交流来针对个人。">ⓘ</span>
3. 禁止 NSFW、冒犯性或恶意内容 <span class="info-tooltip" title="这包括含有恶意链接、裸露、色情、过度粗口的内容，或其他冒犯性、恶意和/或不适合在公共场合出现的内容。">ⓘ</span>
4. 禁止在文字/语音频道或帖子中刷屏 <span class="info-tooltip" title="这包括发布多个帖子或主题、重复发送相同或相似的消息、滥用语音交流频道，或其他包括反复加入/离开语音频道在内的行为。">ⓘ</span>
5. 请使用英语 <span class="info-tooltip" title="BeamMP 内的所有交流应尽可能使用英语，另有指定的特定区域除外。">ⓘ</span>
6. 禁止不当的个人资料 <span class="info-tooltip" title="这包括个人资料名称、照片、简介或其他由用户控制的、不符合 BeamMP/BeamNG/Discord 规则和服务条款的内容。">ⓘ</span>
7. 禁止人肉搜索（doxxing） <span class="info-tooltip" title="禁止公开个人信息（“人肉搜索”），包括但不限于真实姓名、住址、电子邮箱、密码、银行账户和信用卡信息等。">ⓘ</span>
8. 禁止谈论政治 <span class="info-tooltip" title="这包括讨论 BeamMP/BeamNG 或整个游戏领域之外的过去或当前的世界事件。这些话题自有合适的讨论场所，但 BeamMP 不是其中之一。">ⓘ</span>
9. 禁止宣传非 BeamMP/BeamNG 内容 <span class="info-tooltip" title="这包括非 BeamMP 的社区、社交媒体频道或其他外部链接。这既适用于在 BeamMP 社区内发帖，也适用于为个人宣传目的向用户发送未经请求的私信（DM）。">ⓘ</span>
10. 禁止冒充工作人员 <span class="info-tooltip" title="这包括声称自己是 BeamMP 的工作人员，或声称拥有工作人员才有的权限。这也包括模仿工作人员。">ⓘ</span>
11. 禁止利用漏洞 <span class="info-tooltip" title="这包括为谋取个人利益或对他人的体验造成负面影响而利用任何漏洞或疏忽。">ⓘ</span>
12. 严禁分享 Authkey，也严禁使用小号使密钥数量超过规定的免费额度。
13. 遵守所有适用的服务条款（TOS） <span class="info-tooltip" title="这一点很重要，因为要使用我们的 Discord 服务器，还必须遵守诸如 Discord 年龄限制（13 岁以上）之类的限制。">ⓘ</span>
14. 尊重每一个人 <span class="info-tooltip" title="这本应不言自明：你需要尊重身边的每一个人，并据此行事。">ⓘ</span>
15. 内容要与分类或频道的主题相符。 <span class="info-tooltip" title="这本应不言自明：请让你的内容与发布区域的主题保持一致。例如，支持频道应用于帮助他人或寻求支持。">ⓘ</span>
16. 禁止过度使用大写字母（CAPS LOCK）或表情回应/表情符号 <span class="info-tooltip" title="用户应避免过度使用大写字母或表情符号/表情回应，以免干扰对当前重点的理解。">ⓘ</span>
17. 在支持区域发帖之前，请先查看 [BeamMP 常见问题](/zh/players/faq)和 [BeamMP 社区常见问题](https://forum.beammp.com/c/faq/35)。

## Discord 规则

1.    以上所有规则在这里同样适用 <span class="info-tooltip" title="本文档中提到的所有规则都适用于语音聊天。">ⓘ</span>
2.    遵守 Discord 的服务条款和准则 <span class="info-tooltip" title="遵守 Discord 在其服务条款和准则中列出的所有规则。">ⓘ</span>
3.    禁止 NSFW 音频/直播 <span class="info-tooltip" title="玩家不得直播任何违反 BeamMP 规则和 Discord 服务条款的内容。">ⓘ</span>
4.    上一条规则也包括赌博服务/网站。
5.    禁止过度使用音频 <span class="info-tooltip" title="禁止过度使用音效板、播放大音量音乐，或以其他方式利用音频频道故意激怒或针对他人。">ⓘ</span>
6.    禁止反复加入/离开刷屏 <span class="info-tooltip" title="大多数用户可能开启了提示音效，请不要快速地反复加入和离开语音聊天。">ⓘ</span>
7.    禁止纠缠他人（`@'ing`） <span class="info-tooltip" title="这包括在被无视或被拒绝之后，仍然反复要求他人回应。">ⓘ</span>
8.    请把机器人（bot）命令放在专门的命令频道中。
10.   禁止角色扮演 <span class="info-tooltip" title="设立这条规则，是为了避免因缺少上下文而引发问题，也为了防止用户借此规避某些规则。">ⓘ</span>
11.   不要要求用户通过私信（DM）向你求助。所有与支持相关的话题都应放在 BeamMP Discord 服务器中指定的支持区域。
12.   不要提出远程控制他人的电脑，也不要发送含义不明、可能带有恶意和/或具有破坏性的文件/扩展名。
13.   不要讲解和/或发送链接来说明如何盗版、获取非法的软件副本、盗取账号（beaming）或获取付费模组。
14.   不要宣传非 BeamNG/BeamMP 的内容。只允许在专门的[媒体频道](https://discord.com/channels/601558901657305098/705427325646274680)中发送你自己频道的媒体内容。
15.   听从工作人员的指示。如果你认为某位工作人员滥用职权，请私信其负责人或项目管理人员。

## 如何对针对你的处理提出申诉：

如果你的 BeamMP 账号被封禁，请在 BeamMP Accounts 中申诉。请参阅[封禁与申诉](/zh/players/suspensions-and-appeals)。

### 封禁申诉可以通过 <a href="https://docs.google.com/forms/d/1MaTPKM-MHQU5lUtxeOKz3C7OoI6Xbu5RX5AJdX-UOz4" class="inline-onebox">封禁申诉 - BeamMP</a> 提交。

所有通过此表单提交的封禁申诉都会经过彻底调查，涉及至少两（2）名未参与该案件的工作人员/管理团队成员。作出处理的工作人员可以发表意见，但不会以其他方式参与申诉决定。申诉结果为最终结果。BeamMP 保留根据 BeamMP 社区规则（如上所述）、[Discord 服务条款](https://discord.com/terms)及其他因素，自行决定是否允许成员留在社区的权利。

::: warning
如果你被采取了处理措施，则禁止你创建新的 Discord 或 BeamMP 账号来规避封禁。
:::
