# 启动器更新问题

启动器无法更新，或显示空白屏幕？本指南介绍如何手动更新启动器。

在按本指南操作之前，你应该已经使用[我们网站](https://beammp.com)上的安装程序安装了 BeamMP。

## 安装新的启动器

1. 直接从 [GitHub](https://github.com/BeamMP/BeamMP-Launcher/releases/latest/download/BeamMP-Launcher.exe) 下载最新的启动器。
2. 前往存放 `BeamMP-Launcher.exe` 的文件夹。默认位置是 `C:\Users\<username>\AppData\Roaming\`。请把 `<username>` 替换为你的 Windows 用户名。如果你把 BeamMP 安装在了其他位置，例如 `D:\BeamMP-Launcher`，请使用那个文件夹。
3. 用新的启动器替换 BeamMP-Launcher 文件夹中现有的启动器。
4. 像往常一样启动启动器，并检查它是否正常工作。
