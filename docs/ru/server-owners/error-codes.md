# Коды ошибок сервера

На этой странице перечислены сетевые коды ошибок, с которыми вы можете столкнуться при запуске сервера, и что делать в каждом случае. Сам сервер выводит текст ошибки, например после `bind() failed:`, а не её номер. Номера — это коды ошибок Windows Sockets, которые показывают Launcher и Windows.


| Код   | Описание                                   | Возможное решение                                                                                                     |
|-------|--------------------------------------------|-----------------------------------------------------------------------------------------------------------------------|
| 10022 | Проблема с привязкой к порту               | Проверьте, не занят ли порт сервера другой службой. Если занят, используйте другой.                                   |
| 10048 | Адрес уже используется                     | На этом порту работает другой сервер BeamMP или другая программа. Используйте другой порт.                            |
| 10051 | Сеть недоступна                            | Неверная переадресация портов или похожие проблемы. Проверьте, что всё настроено правильно.                           |
| 10052 | Сброс сети                                 | Возникает, если сеть разрывает соединение в момент его установки. Повторите подключение.                              |
| 10053 | Подключение прервано                       | Вызвано тайм-аутом или сетевой ошибкой. Повторите подключение.                                                        |
| 10054 | Соединение сброшено удалённой стороной     | Клиент отключился от вашего сервера.                                                                                  |
| 10060 | Время ожидания подключения истекло         | Проблема с переадресацией портов. См. [шаги по переадресации портов](/ru/server-owners/host-a-server#forward-the-port). |
| 10061 | Подключение отклонено                      | Проблема с переадресацией портов. См. [шаги по переадресации портов](/ru/server-owners/host-a-server#forward-the-port). |
| 10064 | Хост не работает                           | Маловероятная ошибка. Она означает, что хост не работает: либо он выключен, либо порты закрыты.                       |
| 10065 | Хост недоступен                            | Нет интернета или неверная переадресация портов. См. [шаги по переадресации портов](/ru/server-owners/host-a-server#forward-the-port). |

Если нужного кода нет в этом списке, см. [коды ошибок Windows Sockets](https://learn.microsoft.com/en-us/windows/win32/winsock/windows-sockets-error-codes-2), если вы немного разбираетесь в том, как устроены сети и сокеты.
