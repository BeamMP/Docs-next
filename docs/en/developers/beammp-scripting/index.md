# BeamMP Scripting

References for the functions and events you can use in BeamMP Lua code. To write your first plugin, start with [Mod & Resource Creation](/en/developers/mod-and-resource-creation).

- [Mod (In-Game)](/en/developers/beammp-scripting/mod-in-game): functions for client-side plugins.
- [Server, version 3 (latest)](/en/developers/beammp-scripting/server/latest): the server plugin system.
- [Server, version 2 (deprecated)](/en/developers/beammp-scripting/server/legacy-v2): the old system, no longer supported. For servers still on version 2.
