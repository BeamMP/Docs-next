# Игровая документация

BeamMP работает внутри BeamNG.drive, поэтому значительная часть того, что вы пишете для BeamMP, на самом деле является кодом BeamNG.drive. В этом разделе собраны руководства и фрагменты кода для него. Полным справочником служит [документация](https://documentation.beamng.com/) самой BeamNG.

О собственных функциях и событиях BeamMP читайте в [справочниках по скриптингу](/ru/developers/beammp-scripting/).

## Руководства

- [Разработка контента](/ru/game-documentation/content-development/): где узнать о создании карт, объектов и транспорта.
- [UI-приложения (HTML)](/ru/game-documentation/programming/ui-apps-html-cef): как создать приложение, которое отображается на экране игры.
- [Руководство по окну ImGui](/ru/game-documentation/programming/imgui): как создать простое окно ImGui.
