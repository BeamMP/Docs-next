# 游戏文档

BeamMP 运行在 BeamNG.drive 之内，所以你为 BeamMP 编写的很多内容，其实就是 BeamNG.drive 的代码。本部分提供与这些代码相关的指南和代码片段。BeamNG 官方的[文档](https://documentation.beamng.com/)是完整的参考资料。

关于 BeamMP 自己的函数和事件，请参阅[脚本参考](/zh/developers/beammp-scripting/)。
