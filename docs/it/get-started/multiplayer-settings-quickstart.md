# Impostazioni multigiocatore iniziali

BeamMP ha le sue impostazioni multigiocatore. Non devi cambiarne nessuna per giocare. Queste sono quelle che vale la pena conoscere nella tua prima sessione. Ogni impostazione è descritta in [Impostazioni multigiocatore](/it/players/multiplayer-settings).

## Vedere tutte le impostazioni

Attiva **Show advanced options** per vedere tutte le impostazioni multigiocatore. Se è disattivata, vedi solo quelle di base.

## Impostazioni che potresti voler cambiare

| Impostazione | Cosa fa | Cambiala quando |
|---|---|---|
| **New chat menu** | Mostra la chat di gioco in una finestra che puoi trascinare fuori dal gioco, ad esempio su un altro monitor | Vuoi la chat su un secondo schermo |
| **Enable vehicle position smoothing** | Rende il movimento dei veicoli degli altri giocatori più fluido, a intervalli regolari | Un giocatore ha un ping alto, oppure la tua connessione perde molti pacchetti |
| **Use simplified vehicles when available** | Sostituisce i veicoli degli altri giocatori con le loro versioni semplificate, dove disponibili | Le preferisci ai modelli completi |
| **Skip the mod security warning popups** | Nasconde l'avviso mostrato quando ti connetti a un server con mod | Ti connetti spesso agli stessi server |
| **Hide player nametags** | Impedisce la visualizzazione dei nametag | I nametag ti danno fastidio |
| **Enable player vehicle update/edit queuing** | Mette in coda le comparse e le modifiche dei veicoli degli altri giocatori invece di caricarle subito | Vuoi che i veicoli compaiano quando decidi tu; vedi [la coda degli eventi](/it/players/multiplayer-settings#event-queue) |

## Impostazioni da lasciare invariate

- **Disable pausing caused by instabilities** è meglio lasciarla disattivata. Instabilità ripetute possono mandare in crash il gioco.
- **Show network activity in the console** scrive tutto nei file di log, che possono crescere di centinaia di megabyte in pochi minuti.
- **Launcher port** va cambiata solo se la porta 4444 non può essere usata. Se la cambi, cambiala anche in `launcher.cfg`. Vedi [Cambiare la porta del Launcher](/en/troubleshooting/launcher-port).
