# Content Development

Content for BeamNG.drive means maps, props, vehicles, UI apps and Lua mods. A mod you make for the game also works with BeamMP, if the server it joins has it.

We do not have our own guides for creating maps, props or vehicles. BeamNG's documentation covers them:

- [Modding](https://documentation.beamng.com/modding/): the overview of everything you can make.
- [Vehicles](https://documentation.beamng.com/modding/vehicle/): creating vehicles.
- [The World Editor](https://documentation.beamng.com/world_editor/): building and editing maps.
- [UI](https://documentation.beamng.com/modding/ui/): making UI elements.
- [Programming](https://documentation.beamng.com/modding/programming/): Lua, extensions and debugging.

On this site:

- [UI Apps (HTML)](/en/game-documentation/programming/ui-apps-html-cef) shows how to make a UI app.
- [ImGui Window Tutorial](/en/game-documentation/programming/imgui) shows how to create a basic ImGui window.
- To put a mod on a BeamMP server, see [Mod & Resource Creation](/en/developers/mod-and-resource-creation) and [Mod Safety](/en/players/mod-safety).
