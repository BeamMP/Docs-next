# Участие

Вы можете помочь улучшить эту документацию: исправить ошибку, добавить недостающее или написать новую страницу. Эта страница объясняет, как это сделать.

## Перед тем как писать

Прочитайте [руководство по стилю](https://github.com/__repo__/blob/main/STYLE_GUIDE.md). В нём сказано, как должна выглядеть страница, когда использовать каждый блок и как оформлять изображения и ссылки.

Главными считаются английские страницы. Измените английскую страницу, и остальные языки последуют за ней. Чтобы помочь с переводом, см. [Перевод](#translating).

## Редактирование страницы на GitHub

Это самый быстрый способ для исправления орфографии, грамматики и небольших дополнений. Он требует некоторого знания Markdown.

1. Нажмите **Edit this page** внизу страницы, которую хотите изменить.
2. Сделайте форк проекта в свой аккаунт GitHub.
3. Внесите изменения.
4. Зафиксируйте их (commit) в своём форке.
5. Откройте pull request в [@repo@](https://github.com/__repo__).

## Предварительный просмотр изменений локально

Для более крупных правок просматривайте изменения по мере написания.

1. Сделайте форк проекта и клонируйте свой форк.
2. Установите [Node.js](https://nodejs.org) версии 22 или новее, затем выполните `npm install`.
3. Выполните `npm run dev` и откройте адрес, который он выведет. Страница обновляется по мере редактирования.
4. Внесите изменения, затем выполните `npm test` и `npm run check`. Проверка находит нерабочие ссылки, незакрытые блоки, отсутствующие изображения и страницы, которые не отображаются.
5. Зафиксируйте изменения в своём форке и откройте pull request.

## Что будет дальше

Участник BeamMP Mod Team рассматривает ваш pull request и либо одобряет его, либо просит внести изменения. Когда вы внесёте изменения, мы рассмотрим его снова. После слияния он автоматически публикуется.

## Перевод {#translating}

Документация переводится на несколько языков с помощью [GitLocalize](https://gitlocalize.com/repo/9180). GitLocalize может показывать абзац как «не переведённый», хотя он уже переведён, поэтому прежде чем менять страницу, проверьте, что она ещё не переведена.
