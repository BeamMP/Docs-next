# Multiplayer-Einstellungen für den ersten Start

BeamMP hat eigene Multiplayer-Einstellungen. Du musst keine davon ändern, um zu spielen. Diese hier solltest du in deiner ersten Sitzung kennen. Jede Einstellung wird unter [Einstellungen anpassen](/de/players/multiplayer-settings) beschrieben.

## Alle Einstellungen anzeigen

Aktiviere **Show advanced options**, um alle Multiplayer-Einstellungen zu sehen. Ist die Option aus, siehst du nur die grundlegenden.

## Einstellungen, die du vielleicht ändern möchtest

| Einstellung | Was sie bewirkt | Ändere sie, wenn |
|---|---|---|
| **New chat menu** | Zeigt den Ingame-Chat in einem Fenster an, das du aus dem Spiel herausziehen kannst, zum Beispiel auf einen anderen Monitor | du den Chat auf einem zweiten Bildschirm haben möchtest |
| **Enable vehicle position smoothing** | Glättet die Bewegung der Fahrzeuge anderer Spieler in regelmäßigen Abständen | ein Spieler einen hohen Ping hat oder deine Verbindung viele Pakete verliert |
| **Use simplified vehicles when available** | Ersetzt die Fahrzeuge anderer Spieler durch ihre vereinfachten Versionen, sofern vorhanden | du sie den vollständigen Modellen vorziehst |
| **Skip the mod security warning popups** | Blendet die Warnung aus, die beim Verbinden mit einem Server mit Mods erscheint | du dich oft mit denselben Servern verbindest |
| **Hide player nametags** | Verhindert, dass Namensschilder angezeigt werden | dir Namensschilder im Weg sind |
| **Enable player vehicle update/edit queuing** | Reiht das Spawnen und Bearbeiten von Fahrzeugen anderer Spieler in eine Warteschlange ein, statt sie sofort zu laden | Fahrzeuge dann erscheinen sollen, wenn du es willst; siehe [die Ereigniswarteschlange](/de/players/multiplayer-settings#event-queue) |

## Einstellungen, die du in Ruhe lassen solltest

- **Disable pausing caused by instabilities** lässt du am besten ausgeschaltet. Wiederholte Instabilitäten können das Spiel zum Absturz bringen.
- **Show network activity in the console** schreibt alles in die Logdateien, die innerhalb weniger Minuten auf mehrere hundert Megabyte anwachsen können.
- **Launcher port** musst du nur ändern, wenn Port 4444 nicht verwendet werden kann. Wenn du ihn änderst, ändere ihn auch in der `launcher.cfg`. Siehe [Ändern des Launcher-Ports](/de/troubleshooting/launcher-port).
