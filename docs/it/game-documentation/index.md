# Documentazione di gioco

BeamMP gira dentro BeamNG.drive, quindi buona parte di ciò che scrivi per BeamMP è in realtà codice di BeamNG.drive. Questa sezione contiene guide e snippet per quel codice. La [documentazione](https://documentation.beamng.com/) di BeamNG è il riferimento completo.

Per le funzioni e gli eventi propri di BeamMP, consulta i [riferimenti allo scripting](/it/developers/beammp-scripting/).

- [Tutorial finestra ImGui](/it/game-documentation/programming/imgui): crea una semplice finestra ImGui.
