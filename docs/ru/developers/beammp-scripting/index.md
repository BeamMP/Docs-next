# Скриптинг BeamMP

Справочники по функциям и событиям, которые можно использовать в Lua-коде BeamMP. Чтобы написать свой первый плагин, начните со страницы [Создание модов и ресурсов](/ru/developers/mod-and-resource-creation).

- [Мод (в игре)](/ru/developers/beammp-scripting/mod-in-game): функции для клиентских плагинов.
- [Сервер, версия 3 (последняя)](/ru/developers/beammp-scripting/server/latest): система серверных плагинов.
- [Сервер, версия 2 (устаревшая)](/ru/developers/beammp-scripting/server/legacy-v2): старая система, больше не поддерживается. Для серверов, которые всё ещё работают на версии 2.
