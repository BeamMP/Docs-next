# Documentation du jeu

BeamMP fonctionne à l'intérieur de BeamNG.drive : une grande partie de ce que vous écrivez pour BeamMP est donc en réalité du code BeamNG.drive. Cette section propose des guides et des extraits pour ce code. La [documentation](https://documentation.beamng.com/) de BeamNG constitue la référence complète.

Pour les fonctions et événements propres à BeamMP, consultez les [références de script](/fr/developers/beammp-scripting/).

## Guides

- [Développement de contenu](/fr/game-documentation/content-development/) : où apprendre à créer des cartes, des objets et des véhicules.
- [Applications UI (HTML)](/fr/game-documentation/programming/ui-apps-html-cef) : créez une application qui s'affiche à l'écran du jeu.
- [Tutoriel de fenêtre ImGui](/fr/game-documentation/programming/imgui) : créez une fenêtre ImGui de base.
