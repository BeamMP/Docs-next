### Ich habe einen Fehler oder einen Exploit gefunden. Was soll ich tun?

Wenn es ein Code-Problem ist und du GitHub bedienen kannst, eröffne ein „Issue“ im passenden Repository auf unserem [GitHub](https://github.com/BeamMP). Wir arbeiten issue-basiert: Auch wenn du schon einen Fix hast, eröffne zuerst ein Issue und dann einen „Pull Request“, der es löst. Mehr zum Mitwirken steht im [Leitfaden zum Mitwirken](https://github.com/BeamMP/BeamMP/blob/development/CONTRIBUTING.md).

Wenn du kein GitHub-Konto hast oder nicht weißt, wie man GitHub benutzt, kannst du uns auf anderem Weg erreichen:

- Wenn es nicht vertraulich ist, schreibe einen Beitrag im [BeamMP-Forum](https://forum.beammp.com) oder melde es auf dem [Discord-Server](https://discord.gg/beammp).
- Wenn es vertraulich ist, melde es direkt einem Teammitglied auf [Discord](https://discord.gg/beammp).
