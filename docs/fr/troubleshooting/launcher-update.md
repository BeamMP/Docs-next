# Problèmes de mise à jour du lanceur

Le lanceur ne parvient pas à se mettre à jour, ou affiche un écran vide ? Ce guide explique comment le mettre à jour manuellement.

Vous devez déjà avoir installé BeamMP à l'aide de l'installateur fourni sur [notre site web](https://beammp.com) avant de suivre ces étapes.

## Installer un nouveau lanceur

1. Téléchargez directement le dernier lanceur depuis [GitHub](https://github.com/BeamMP/BeamMP-Launcher/releases/latest/download/BeamMP-Launcher.exe).
2. Rendez-vous dans le dossier qui contient `BeamMP-Launcher.exe`. Par défaut, il s'agit de `C:\Users\<username>\AppData\Roaming\`. Remplacez `<username>` par le nom d'utilisateur de votre session Windows. Si vous avez installé BeamMP ailleurs, par exemple dans `D:\BeamMP-Launcher`, utilisez ce dossier.
3. Remplacez le lanceur existant dans le dossier BeamMP-Launcher par le nouveau.
4. Démarrez le lanceur comme d'habitude et vérifiez qu'il fonctionne.
