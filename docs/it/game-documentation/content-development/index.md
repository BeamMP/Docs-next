# Sviluppo dei contenuti

Per contenuti di BeamNG.drive si intendono mappe, oggetti, veicoli, app UI e mod Lua. Una mod che crei per il gioco funziona anche con BeamMP, se il server a cui ti connetti la include.

Non abbiamo guide nostre per creare mappe, oggetti o veicoli. Li trovi nella documentazione di BeamNG:

- [Modding](https://documentation.beamng.com/modding/): la panoramica di tutto ciò che puoi creare.
- [Vehicles](https://documentation.beamng.com/modding/vehicle/): creare veicoli.
- [The World Editor](https://documentation.beamng.com/world_editor/): costruire e modificare mappe.
- [UI](https://documentation.beamng.com/modding/ui/): creare elementi UI.
- [Programming](https://documentation.beamng.com/modding/programming/): Lua, estensioni e debug.

Su questo sito:

- [App UI (HTML)](/it/game-documentation/programming/ui-apps-html-cef) mostra come creare un'app UI.
- [Tutorial finestra ImGui](/it/game-documentation/programming/imgui) mostra come creare una semplice finestra ImGui.
- Per mettere una mod su un server BeamMP, consulta [Creazione di Mod e Risorse](/it/developers/mod-and-resource-creation) e [Sicurezza mod](/it/players/mod-safety).
