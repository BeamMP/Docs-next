# First-Time Multiplayer Settings

BeamMP has its own multiplayer settings. You do not need to change any of them to play. These are the ones worth knowing about in your first session. Every setting is described in [Multiplayer Settings](/en/players/multiplayer-settings).

## Find the settings

In BeamNG.drive, click **Options** and select **BeamMP**. All the settings are on that page, in groups. There is no switch for hidden settings.

## Settings you may want to change

| Setting | What it does | Change it when |
|---|---|---|
| **New chat menu** | Shows the in-game chat in a window you can drag out of the game, for example onto another monitor | You want chat on a second screen |
| **Enable vehicle position smoothing** | Smooths the position data of players with an unstable connection, which reduces vehicle warping | A player has high ping, or your connection drops a lot of packets |
| **Use simplified vehicles when available** | Replaces other players' vehicles with the simplified traffic versions of BeamNG.drive, where there is one | Performance is poor on a busy server |
| **Skip the mod security warning popup** | Hides the warning shown when you connect to a server that has mods | You connect to the same servers often, and you trust them |
| **Hide player nametags** | Stops nametags being drawn | Nametags get in the way |
| **Enable player vehicle update/edit queuing** | Queues other players' vehicle spawns and edits instead of loading them at once | You want vehicles to appear when you choose; see [the event queue](/en/players/multiplayer-settings#event-queue) |
| **Enable Config Cloning Protection** | Stops other players cloning or saving your vehicles | You do not want others to copy your build |

## Settings to leave alone

- **Show network activity in the console** writes everything to the log files, which can grow by hundreds of megabytes in minutes.
- **Launcher port** only needs changing if port 4444 cannot be used. If you change it, set `Port` in `Launcher.cfg` to the same number. See [Changing the Launcher Port](/en/troubleshooting/launcher-port).
