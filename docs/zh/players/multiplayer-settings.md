# 多人模式设置

这些是 BeamMP 多人模式设置页面上的设置。每一项都是折叠的条目：展开后可以看到它在开启和关闭时分别有什么作用。如果你是新手，请先看[首次多人模式设置](/zh/get-started/multiplayer-settings-quickstart)。

## 常规

::: details 显示高级选项
如果启用，你将看到所有多人模式设置
如果禁用，你将只看到基本的多人模式设置
:::

::: details 启用配置克隆保护
如果启用，你刷出的车辆配置将不会被其他玩家保存

如果禁用，你刷出的车辆配置可以被其他玩家保存
:::

:::: details 禁用因不稳定导致的暂停
如果启用，物理不稳定不会导致你的游戏暂停

如果禁用，物理不稳定会导致你的游戏暂停

::: note
建议保持禁用，因为反复出现的不稳定可能会导致游戏崩溃
:::
::::

::: details 可用时使用简化车辆
如果启用，游戏会在有简化版本（来自 AI 交通）时，用简化版本替换其他玩家的车辆

如果禁用，游戏将使用原本的车辆模型
:::

:::: details 新聊天菜单
如果启用，游戏内聊天将显示在一个 [IMGUI](https://github.com/ocornut/imgui) 窗口中，例如可以把它从游戏中拖出，放到另一台显示器上

如果禁用，游戏内聊天将显示在 UI 应用程序中

::: note
将 IMGUI 窗口拖出游戏主窗口可能会导致性能问题，还可能让屏幕录制软件录下聊天窗口，而不是游戏主窗口
:::
::::

::: details 启用车辆位置平滑
如果启用，BeamMP 会使用一种算法，将车辆位置更新平滑到固定的时间间隔。在延迟较高的玩家之间，或连接丢包率较高时，这会有所帮助

如果禁用，BeamMP 会在收到车辆位置时立即更新
:::

::: details 跳过模组安全警告弹窗
如果启用，在尝试连接到带有模组的服务器时，不会显示模组安全提示框

如果禁用，每当你连接到带有模组的服务器时，都会显示模组安全提示框
:::

::: details 启用玩家车辆更新/编辑排队处理
如果启用，其他玩家的车辆刷出和编辑将被放入队列。详情请参阅[事件队列](#event-queue)一节

如果禁用，其他玩家的车辆刷出和编辑将被游戏立即加载
:::

::: details 启用自动部件同步
如果启用，你的车辆零件会在几秒钟后自动同步给其他玩家

如果禁用，你需要点击零件选择器中的零件同步按钮，才能把同步发送给其他玩家
:::

::: details 禁用切换至其他玩家车辆
如果启用，按 Tab 键切换车辆时会跳过其他玩家的车辆

如果禁用，按 Tab 键切换车辆时会循环切换每一辆已刷出的车辆
:::

:::: details 车辆靠近时逐渐淡出
如果启用，其他车辆在靠近时会淡出

如果禁用，无论距离远近，其他车辆都会保持完全可见

::: note
这只会影响车辆可见的 3D 网格，不会影响其物理节点-梁网格。要同时禁用物理，你需要在游戏性设置中启用 `Simplified collision physics`
:::
::::

::: details 显示玩家ID
如果启用，游戏内玩家列表会多出一列，显示每位玩家的 ID。对开发或管理很有用

如果禁用，游戏内玩家列表将只显示玩家名称和延迟这两列
:::

::: details 允许在游戏内刷新服务器列表
如果启用，服务器列表会在游玩期间按固定时间间隔更新。这可能会导致卡顿

如果禁用，服务器列表只会在你打开主菜单时更新一次
:::

## 事件队列 {#event-queue}

::: details 高亮显示排队队列中的玩家
如果启用，有排队事件的玩家将在游戏内玩家列表中高亮显示

如果禁用，玩家不会被单独高亮显示
:::

::: details 应用车辆更改的方式
如果设置为 `Left mouse button`，在玩家列表中用鼠标左键点击玩家名称将加载排队的事件，用鼠标右键点击则会观战该玩家

如果设置为 `Right mouse button`，在玩家列表中用鼠标右键点击玩家名称将加载排队的事件，用鼠标左键点击则会观战该玩家
:::

::: details 自动应用排队中的车辆更改
如果启用，当你的速度低于速度阈值的时间达到所设定的超时时长后，排队的事件将被自动加载

如果禁用，排队的事件只能手动加载，方法是点击屏幕顶部的 `Events` 按钮，或点击玩家列表中的玩家名称
:::

::: details 队列应用速度限制
此设置定义了自动加载事件队列的速度阈值。你的车辆必须在长于 `Queue apply timeout` 的时间内低于此速度，排队的事件才会被加载
:::

::: details 队列应用超时时间
此设置定义了自动加载事件队列的时间延迟。你的车辆必须在这段时间内都慢于 `Queue apply speed threshold`，排队的事件才会被加载
:::

::: details 观战其他玩家时跳过队列
如果启用，在你观战其他玩家时，事件会被立即加载

如果禁用，事件会被放入队列，就像你操控自己的车辆时一样
:::

::: details 不要将独轮车（雪人/Beamlings）加入队列
如果启用，与 Snowmen/Beamlings 有关的事件会被立即加载

如果禁用，Snowmen/Beamlings 会和其他车辆一样被放入队列
:::

## 默认独轮车

::: details 默认独轮车配置
此设置定义了默认加载的独轮车变体。你可以在预设配置之间选择，如果你保存过自定义的独轮车配置，也可以选择自己的配置
:::

::: details 自动保存您上次使用的独轮车
如果启用，你上次使用的独轮车会被自动保存，并在你再次刷出时重新加载

如果禁用，每次都会刷出你的默认独轮车配置
:::

## 斑点

::: details 为未生成的车辆启用 Blobs
如果启用，你会在未刷出的车辆所在位置看到一个占位球，即斑点（blob）

如果禁用，未刷出的车辆将不可见
:::

:::: details 调整颜色
::: details 可见
如果启用，将绘制一个斑点，使用下面的颜色

如果禁用，则不会为指定的功能绘制斑点
:::

::: details HEX 颜色值（例如：#FF6400）
队列车辆：车辆在排队等待刷出时，斑点所使用的颜色。标准值 #FF6400

非法车辆：车辆非法时（例如通过旁加载的模组），斑点所使用的颜色。标准值 #000000

已删除的车辆：车辆被用户删除时，斑点所使用的颜色。标准值 #333333
:::
::::

## 昵称标签

::: details 隐藏玩家的名称标签
如果启用，将不会绘制玩家的昵称标签

如果禁用，玩家的昵称标签将根据其车辆的相对位置绘制
:::

::: details 显示与其他玩家的距离
如果启用，昵称标签前面会加上与相应车辆的距离

如果禁用，昵称标签中不会显示额外的距离
:::

::: details 名称标签淡入淡出
如果启用，昵称标签将根据 `Fade distance` 和 `Invert nametag fade direction` 淡入/淡出

如果禁用，无论与相应车辆的距离如何，昵称标签都将以标准不透明度绘制
:::

:::: details 淡出距离/反转标签淡出方向
::: details 淡出
玩家离得越远，昵称标签就越不明显

`Fade distance` 定义了昵称标签以最低不透明度绘制时的距离
:::

::: details 淡入
玩家离得越远，昵称标签就越明显

`Fade distance` 定义了昵称标签以最高不透明度绘制时的距离
:::
::::

::: details 不要完全隐藏名称标签
如果启用，昵称标签不会变得完全不可见，无论距离多远，它都会保留最低的不透明度

如果禁用，昵称标签可以变得完全不可见
:::

::: details 缩短名称标签和角色标签
如果启用，`Nametag length limit` 会将昵称标签和角色标签截断到所设置的字符数上限

如果禁用，昵称标签和角色标签将以完整长度显示
:::

::: details 在车辆名称标签下方显示观战者名称标签
如果启用，观战者的名称会被添加到玩家昵称标签的下方

如果禁用，昵称标签中不会添加观战者的名称
:::

::: details 观战者名称标签使用相同颜色
如果启用，观战者的名称周围始终是灰色背景

如果禁用，观战者的名称周围是彩色背景，以体现观战者的角色
:::

## 其他设置

:::: details 在控制台显示网络活动
如果启用，BeamMP 的网络活动将显示在控制台中

如果禁用，控制台中将不再显示网络活动

::: danger
请谨慎使用此设置，因为所有控制台输出也会被写入日志文件

启用此设置后，日志文件可能在几分钟内增长数百 MB
:::
::::

:::: details 启动器端口：
此设置定义了与启动器通信所使用的端口

只有在标准端口 4444 无法使用时才应修改

别忘了也要在启动器一侧修改它，方法是修改 `Launcher.cfg`

::: tip
所指定的端口只是两个端口中的第一个，所使用的第二个端口紧随其后，即所设端口 + 1

第一个端口传输核心网络数据包，第二个端口传输游戏网络数据包，两者都通过 TCP 传输
:::
::::
