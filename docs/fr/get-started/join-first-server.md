# Rejoindre votre premier serveur

Vous avez [installé BeamMP](/fr/get-started/install-beammp). Il ne reste plus qu'à démarrer le lanceur et à vous connecter à un serveur.

## Démarrer le multijoueur

1. Démarrez le lanceur BeamMP. Une fenêtre de terminal s'ouvre. Le lanceur télécharge le mod BeamMP, l'active et démarre BeamNG.drive. Ne fermez pas la fenêtre du terminal : le lanceur doit rester ouvert pendant que vous jouez. Quand vous fermez le jeu, le lanceur se ferme aussi.
2. Dans le menu principal de BeamNG.drive, cliquez sur **Dépôt**, puis ouvrez l'onglet **Gestionnaire de mods**. Vérifiez que `multiplayerbeammp` est la seule entrée sous **Mods actifs**.
3. Retournez au menu principal, cliquez sur **Plus...**, puis sur **BeamMP**.
4. Connectez-vous avec votre [compte BeamMP](/fr/players/account), ou jouez en invité. Tous les serveurs n'acceptent pas les invités. Le lanceur vous garde connecté grâce à un fichier nommé `key` dans son dossier. Ne partagez pas ce fichier.
5. Choisissez un serveur et cliquez sur **Connect**.

::: info La connexion peut prendre du temps
Lorsque vous chargez une carte où de nombreux véhicules sont déjà apparus, la connexion peut être plus longue que prévu.
:::

## Si vous n'arrivez pas à vous connecter

- **Il n'y a pas d'entrée BeamMP sous Plus...** Vérifiez que le mod BeamMP est présent et actif dans le **Gestionnaire de mods**, puis appuyez sur `Ctrl` + `L`.
- **Un VPN est activé.** Tous les types de VPN peuvent causer des problèmes de connexion. Désactivez-le et réessayez.
- **Le lanceur affiche une erreur.** Cherchez-la dans les [codes d'erreur](/fr/troubleshooting/error-codes) ou dans la [FAQ du forum](https://forum.beammp.com/c/faq/35).
- **Sous Linux, une deuxième connexion échoue.** Après que vous avez quitté un serveur, le lanceur peut ne pas parvenir à se connecter au suivant. Il affiche alors `(Proxy) bind failed with error: 98` ou `Connection still alive terminating`. Fermez le jeu et le lanceur, puis relancez-les.

Pour plus d'aide, consultez la page de [dépannage](/fr/troubleshooting/), ou posez vos questions sur le [forum](https://forum.beammp.com) ou sur le [serveur Discord](https://discord.gg/beammp).

Étape suivante : [vérifier les paramètres de première configuration](/fr/get-started/multiplayer-settings-quickstart).
