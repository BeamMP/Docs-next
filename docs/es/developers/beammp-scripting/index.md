# Scripting de BeamMP

Referencias de las funciones y los eventos que puedes usar en el código Lua de BeamMP. Para escribir tu primer plugin, empieza por [Creación de Mods y Recursos](/es/developers/mod-and-resource-creation).

- [Mod (En el Juego)](/es/developers/beammp-scripting/mod-in-game): funciones para plugins del lado del cliente.
- [Servidor, versión 3 (última)](/es/developers/beammp-scripting/server/latest): el sistema de plugins del servidor.
- [Servidor, versión 2 (obsoleta)](/es/developers/beammp-scripting/server/legacy-v2): el sistema antiguo, que ya no recibe soporte. Para servidores que aún usan la versión 2.
