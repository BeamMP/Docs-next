# Настройка сервера

Параметры сервера BeamMP, как назвать его и задать теги, а также пути к стандартным картам. Чтобы установить сервер, см. [Запуск сервера](/ru/server-owners/host-a-server). Чтобы прочитать журнал или обновить сервер, см. [Обслуживание сервера](/ru/server-owners/maintenance).

## Файл ServerConfig

Конфигурация сервера — файл `ServerConfig.toml` — использует [формат TOML](https://toml.io/en/).

::: info Старый файл конфигурации
Старый файл конфигурации сервера назывался `Server.cfg`. Он больше не используется, и сервер выдаёт предупреждение, если он всё ещё есть. Эти два формата **не** совместимы.
:::

В конфигурации два раздела: `[General]` и `[Misc]`. Значения по умолчанию указаны для версии сервера 3.9.4.

### Раздел `[General]` {#the-general-section}

| Ключ | По умолчанию | Значение | Что делает |
|---|---|---|---|
| Port | `30814` | 1024-65535 | Сетевой порт, на котором сервер будет доступен. Сервер использует его и для TCP, и для UDP. (Должен быть уникальным и не использоваться другой службой на том же хосте). |
| AuthKey | пусто | Формат AuthKey `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`, где все x — буквы и цифры | Нужен, чтобы идентифицировать публичный сервер на бэкенде. Если длина ключа не равна 36 символам, сервер при запуске выводит предупреждение. |
| AllowGuests | `true` | true/false | Разрешено ли гостям заходить на сервер. Если параметр отключён (`false`), гостю, который пытается зайти, будет отказано. |
| LogChat | `true` | true/false | Если включено (true), сообщения чата записываются в консоль и в файл `Server.log`. |
| Debug | `false` | true/false | Если включено (true), в журнале показывается больше сообщений и больше информации. Включите это, если у вас возникли проблемы. Из-за этого размер файла журнала резко вырастет. |
| IP | `"::"` | Локальный IP-адрес одного из сетевых интерфейсов хоста | Сервер привязывается к этому IP-адресу. Это **не** ваш публичный IP. Используйте его, если у компьютера несколько сетевых интерфейсов. Для работы сервера менять его не нужно. Значение по умолчанию `"::"` принимает подключения на всех интерфейсах. |
| Private | `true` | true/false | Если включено (true), ваш сервер не показывается в списке серверов. Любой, кто знает правильные IP и порт, всё равно сможет подключиться. |
| InformationPacket | `true` | true/false | Если включено (true), сервер разрешает неаутентифицированным клиентам получать ту же информацию, что и в списке серверов, но напрямую от сервера. |
| Name | `"BeamMP Server"` | Любой «текст» | Показывается как название вашего сервера в списке серверов. С помощью специальных символов можно оформить его цветом и стилями. |
| Tags | `"Freeroam"` | См. список допустимых тегов ниже. | Теги для поиска, например Police, Racing и т. д. |
| MaxCars | `1` | Любое число ≥ 1 | Максимальное количество машин на игрока. Все лишние машины, которые игрок попытается создать, будут сразу удалены. Пеший режим (unicycle) не учитывается. |
| MaxPlayers | `8` | Любое число ≥ 1 | Максимальное количество игроков на сервере. На число транспортных средств это не влияет. Когда сервер заполнен, подключающемуся игроку отказывают с сообщением «Server full!», если только плагин не пропускает его (см. `onPlayerAuth` в [справочнике по скриптингу](/ru/developers/beammp-scripting/server/latest#onplayerauth)). |
| Map | `"/levels/gridmap_v2/info.json"` | Корректный путь к карте, например `/levels/gridmap_v2/info.json` | Карта, которую будет проводить ваш сервер. Она должна быть установлена по умолчанию (список ниже) или как мод сервера. |
| Description | `"BeamMP Default Description"` | Любой «текст» | Показывается как описание сервера в списке серверов (если сервер публичный). С помощью специальных символов можно оформить его цветом и стилями. |
| ResourceFolder | `"Resources"` | Корректный путь к папке, например "D:\Server\BeamMP\Resources" | Удобно, если нужно хранить сервер и папку ресурсов отдельно. |

### Раздел `[Misc]` {#the-misc-section}

| Ключ | По умолчанию | Значение | Что делает |
|---|---|---|---|
| ImScaredOfUpdates | `true` | true/false | Если включено (`true`), скрывает периодическое сообщение о выходе новой версии сервера. Сервер сам не обновляется: см. [Обслуживание сервера](/ru/server-owners/maintenance#updating-the-server). |
| UpdateReminderTime | `"30s"` | Число с добавленным `s`, `min`, `h` или `d`, например `30s` | Как часто в терминале выводится напоминание об обновлении. `30d` — раз в 30 дней, `0.5min` — раз в полминуты. |

::: warning Сервер перезаписывает этот файл
При каждом запуске сервер заново записывает `ServerConfig.toml`, сохраняя только текущие значения параметров разделов `[General]` и `[Misc]`. Добавленные вами комментарии и разделы, добавленные плагинами (например, `[MyMod]`), удаляются. Значения, заданные через [переменные окружения](/ru/server-owners/manual#general-settings), тоже записываются в файл, если не задана переменная `BEAMMP_PROVIDER_DISABLE_CONFIG`.
:::

AuthKey вы **обязательно** должны задать сами. По умолчанию он пуст. Укажите AuthKey, который вы получили при [установке сервера](/ru/server-owners/host-a-server). Никому его не передавайте и полностью закрашивайте его на скриншотах.

### Оформление названия сервера {#customize-the-look-of-your-server-name}

Поставьте эти специальные символы перед текстом, и к нему в списке серверов будет применён эффект:

| Значение | Описание                         |
|:-----:|----------------------------------|
| `^r`  | Сброс                            |
| `^p`  | Новая строка (только в описаниях) |
| `^n`  | Подчёркивание                    |
| `^l`  | Жирный                           |
| `^m`  | Зачёркивание                     |
| `^o`  | Курсив                           |
| `^0`  | Чёрный                           |
| `^1`  | Синий                            |
| `^2`  | Зелёный                          |
| `^3`  | Голубой                          |
| `^4`  | Красный                          |
| `^5`  | Розовый                          |
| `^6`  | Оранжевый                        |
| `^7`  | Серый                            |
| `^8`  | Тёмно-серый                      |
| `^9`  | Светло-фиолетовый                |
| `^a`  | Светло-зелёный                   |
| `^b`  | Светло-голубой                   |
| `^c`  | Тёмно-оранжевый                  |
| `^d`  | Светло-розовый                   |
| `^e`  | Жёлтый                           |
| `^f`  | Белый                            |

### Теги сервера

Теги позволяют людям искать серверы определённого типа. Ваш serverConfig.toml создаётся с тегом freeroam: `Tags = "Freeroam"`.

Можно добавить несколько тегов через запятую: `Tags = "Events,Offroad,lang:english"`. Регистр не важен.
