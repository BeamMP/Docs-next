# Server Owners

Everything you need to host and look after a BeamMP server.

## Set up a server

- [Host a Server](/en/server-owners/host-a-server): choose between hosting at home and a hosting company, then install, configure and join your server.
- [Get an AuthKey](/en/server-owners/authkey): create the key a public server needs, and manage your keys.
- [Port Forwarding](/en/server-owners/port-forwarding): let players outside your home reach a server you host at home.

## Look after your server

- [Server Configuration](/en/server-owners/configuration): every `ServerConfig.toml` setting, and the stock map paths.
- [Installing Mods](/en/server-owners/mods): vehicle mods, maps, server plugins and protected mods.
- [Server Customization](/en/server-owners/server-customization): colours and styles for your server's name, and tags.
- [Server Maintenance](/en/server-owners/maintenance): the log file and updating the server.
- [Server Manual](/en/server-owners/manual): environment variables, the `Resources` folder, command-line arguments, console commands and limits.

## When something goes wrong

- [Check for CGNAT](/en/server-owners/cgnat): why nobody can join even though the port is forwarded.
- [Server Error Codes](/en/server-owners/error-codes): what the network error codes mean.
- [Server FAQ](/en/server-owners/faq): common questions, and what to do when players cannot join.
