# Настройки мультиплеера

Это настройки на странице **BeamMP** в параметрах BeamNG.drive, как в BeamMP 4.22 для BeamNG.drive 0.39. Чтобы открыть их, нажмите **Настройки** и выберите вкладку **BeamMP**. Все настройки всегда видны: переключателя, который скрывает расширенные настройки, нет.

Каждая настройка ниже — свёрнутый блок. Откройте его, чтобы увидеть значение по умолчанию и что настройка делает во включённом и выключенном состоянии. Заголовки соответствуют группам на странице: **Общие параметры**, **Vehicle Update Queue**, **Blobs**, **Пользовательский интерфейс**, **Игроки** и **Расширенные параметры**. Если вы новичок, начните со страницы [Первичная настройка мультиплеера](/ru/get-started/multiplayer-settings-quickstart).

## Общие параметры {#general}

::: details Enable Config Cloning Protection
По умолчанию: выключено.

Если включено, другие игроки не смогут клонировать или сохранять ваши транспортные средства. При попытке они увидят **Vehicle Clone Error** или **Vehicle Save Error**. Изменение настройки также обновляет уже созданные вами транспортные средства.

Если выключено, другие игроки смогут клонировать и сохранять ваши транспортные средства.
:::

::: details Disable switching to other players vehicles
По умолчанию: выключено.

Если включено, при переключении между транспортными средствами транспорт других игроков пропускается, пока у вас есть собственное транспортное средство.

Если выключено, при переключении перебираются все созданные транспортные средства.

Юницикл других игроков пропускается всегда, независимо от этой настройки.
:::

::: details Automatically save your last used Unicycle
По умолчанию: включено.

Если включено, BeamMP сохраняет конфигурацию вашего юницикла, когда вы его удаляете, и использует эту конфигурацию при следующем создании юницикла.

Если выключено, конфигурация вашего юницикла при удалении не сохраняется.
:::

## Очередь событий {#event-queue}

В игре эта группа называется **Vehicle Update Queue**. Когда другой игрок создаёт транспортное средство или изменяет его, BeamMP может поставить изменение в очередь, а не загружать его сразу, чтобы загрузка не мешала вам ехать.

Пока изменения ждут, сообщение сообщает, сколько их, а в панели сессии в верхней части экрана появляется кнопка **Events queued**. Два числа на кнопке — это число ожидающих появлений и число ожидающих изменений, именно в таком порядке. Кнопка появляется, только когда в очереди что-то есть. Если у вас нет транспортного средства, изменения из очереди загружаются сразу.

Изменения из очереди загружаются, когда:

- вы нажимаете **Events queued** в верхней части экрана.
- вы нажимаете клавишу, назначенную на **Queue Events**. Назначьте её в категории **BeamMP** в настройках управления.
- вы щёлкаете по имени игрока, пока в **Playerlist left click action** выбрано **Queue events**. Так загружаются изменения только этого игрока. То же делает **Queue events** в меню, которое открывается правой кнопкой мыши по игроку.
- начинается автоматическая загрузка, описанная ниже.

::: details Enable player vehicle update/edit queuing
По умолчанию: включено.

Если включено, появление и изменения транспортных средств других игроков ждут в очереди, пока их не загрузит одно из действий выше.

Если выключено, появление и изменения транспортных средств других игроков загружаются сразу.
:::

::: details Automatically apply queued vehicle changes
По умолчанию: включено. Показывается, только пока включена очередь.

Если включено, изменения из очереди загружаются, когда ваше транспортное средство двигалось со скоростью не выше **Queue apply speed threshold** в течение времени, заданного в **Queue apply timeout**.

Если выключено, изменения из очереди загружаются, только когда вы загружаете их сами.
:::

::: details Queue apply speed threshold
По умолчанию: 2 м/с. Ползунок от 0 до 10 м/с. Показывается, только пока включена автоматическая загрузка.

Чтобы изменения из очереди загрузились, ваше транспортное средство должно двигаться со скоростью не выше этого порога в течение времени, заданного в **Queue apply timeout**.
:::

::: details Queue apply timeout
По умолчанию: 3 с. Ползунок от 0 до 20 с. Показывается, только пока включена автоматическая загрузка.

Чтобы изменения из очереди загрузились, ваше транспортное средство должно двигаться со скоростью не выше **Queue apply speed threshold** в течение этого времени.
:::

::: details Enable automatic part sync
По умолчанию: включено.

Если включено, внесённое вами изменение деталей транспортного средства отправляется другим игрокам примерно через 15 секунд после вашего последнего изменения.

Если выключено, изменения ваших деталей автоматически не отправляются.
:::

::: details Skip queue if spectating others
По умолчанию: выключено.

Если включено, изменения из очереди загружаются сразу, пока транспортное средство, в котором вы находитесь, не ваше.

Если выключено, изменения ждут в очереди так же, как когда вы управляете собственным транспортным средством.
:::

::: details Don't queue Unicycles (Snowmen/Beamlings)
По умолчанию: включено.

Если включено, появление и изменения юницикла других игроков загружаются сразу.

Если выключено, юницикл ставится в очередь так же, как и другие транспортные средства.
:::

## Капли {#blobs}

Капля — это цветной шар, который заменяет транспортное средство, ещё не появившееся у вас. У неё один из четырёх цветов:

- Цвет для очереди: транспортное средство ждёт в очереди.
- Цвет для недопустимого: транспортное средство нельзя создать, потому что его мода нет.
- Цвет для удалённого: вы удалили это транспортное средство. Чтобы вернуть его, щёлкните правой кнопкой мыши по его владельцу в списке игроков и выберите **Queue deleted vehicles**.
- Пурпурный: любое другое транспортное средство, которое ещё не появилось. Этот цвет изменить нельзя.

::: details Enable blobs for unspawned vehicles
По умолчанию: включено.

Если включено, вместо каждого ещё не созданного транспортного средства вы видите каплю.

Если выключено, ещё не созданное транспортное средство невидимо.
:::

::: details Queued vehicle
По умолчанию: показывается, `#FF6400`.

Флажок **Queued vehicle** включает или выключает каплю для транспортных средств в очереди. Поле **HEX color value (ex: #FF6400)** задаёт её цвет.
:::

::: details Illegal vehicle
По умолчанию: показывается, `#000000`.

Флажок **Illegal vehicle** включает или выключает каплю для транспортных средств, которые нельзя создать. Поле **HEX color value (ex: #FF6400)** задаёт её цвет.
:::

::: details Deleted vehicle
По умолчанию: показывается, `#333333`.

Флажок **Deleted vehicle** включает или выключает каплю для транспортных средств, которые вы удалили. Поле **HEX color value (ex: #FF6400)** задаёт её цвет.
:::

## Пользовательский интерфейс {#user-interface}

::: details Skip the mod security warning popup
По умолчанию: выключено.

Если включено, предупреждение о безопасности модов не показывается при подключении к серверу с модами. Моды скачиваются без запроса.

Если выключено, предупреждение показывается при каждом подключении к серверу с модами. См. [Безопасность модов](/ru/players/mod-safety#the-mod-security-warning).
:::

::: details Allow the serverlist to refresh ingame
По умолчанию: выключено.

Если включено, список серверов можно обновлять, пока вы находитесь в сессии. Это может вызывать резкие просадки производительности.

Если выключено, список серверов продолжает показывать список, который был до вашего подключения, пока вы не выйдете из сессии.
:::

::: details HUD App Style
По умолчанию: **Old**. Варианты: **Old** и **Redesign**.

Эта настройка задаёт внешний вид UI-приложений BeamMP: панели сессии, списка игроков и чата.
:::

:::: details New chat menu
По умолчанию: выключено.

Если включено, внутриигровой чат отображается в окне [ImGui](https://github.com/ocornut/imgui), которое можно вынести за пределы игры на другой монитор. См. раздел [Окно чата](#the-chat-window).

Если выключено, внутриигровой чат отображается в UI-приложении **BeamMP Chat**.

::: warning
Вынос окна ImGui за пределы главного окна игры может снизить производительность, а также сбить программы записи экрана, и они запишут окно чата вместо игры.
:::
::::

### Ники {#nametags}

Остальные настройки ников недоступны, пока включено **Hide player nametags**.

::: details Hide player nametags
По умолчанию: выключено.

Если включено, ники не отображаются.

Если выключено, ник каждого игрока отображается над его транспортным средством. Действие **Player Nametags** в настройках управления скрывает и снова показывает все ники до перезапуска игры.
:::

::: details Show distance from other players
По умолчанию: включено.

Если включено, в конце ника показывается расстояние до транспортного средства, если оно больше 10 м. Расстояние показывается в системе единиц игры.

Если выключено, расстояние в нике не показывается.
:::

::: details Hide nametags behind objects
По умолчанию: выключено.

Если включено, объекты, например здания, скрывают ник, который находится за ними.

Если выключено, ники отображаются поверх всего.
:::

::: details Shorten nametag and role tags
По умолчанию: выключено.

Если включено, длинные имена обрезаются до **Nametag length limit**, а метки ролей используют краткую форму, например `[EA]` вместо `[Early Access]`.

Если выключено, имена и метки ролей показываются полностью.
:::

::: details Nametag length limit
По умолчанию: 32. Ползунок от 0 до 50. Доступно, пока включено **Shorten nametag and role tags**.

Это наибольшее число символов имени, которое показывается. Имя, которое длиннее лимита больше чем на три символа, обрезается до лимита и заканчивается на `...`.
:::

::: details Show spectators' nametag under vehicle nametags
По умолчанию: включено.

Если включено, имена игроков, которые наблюдают за транспортным средством, показываются под его ником.

Если выключено, наблюдатели не показываются.
:::

::: details Same color for spectator nametags
По умолчанию: выключено. Доступно, пока включено **Show spectators' nametag under vehicle nametags**.

Если включено, у ников всех наблюдателей один и тот же серый фон.

Если выключено, у ника наблюдателя фон соответствует роли наблюдателя.
:::

::: details Fade nametags in/out
По умолчанию: выключено.

Если включено, ник становится прозрачнее в зависимости от расстояния до транспортного средства, с учётом **Fade distance**. **Invert nametag fade direction** определяет, в какую сторону он исчезает.

Если выключено, ник отображается с полной непрозрачностью на любом расстоянии.
:::

::: details Fade distance
По умолчанию: 40 м. Ползунок от 0 до 1500 м. Доступно, пока включено **Fade nametags in/out**.

Ник полностью виден рядом с транспортным средством и полностью прозрачен на этом расстоянии. Если включено **Invert nametag fade direction**, всё наоборот.
:::

::: details Don't fully hide nametags
По умолчанию: выключено. Доступно, пока включено **Fade nametags in/out**.

Если включено, ник сохраняет минимальную непрозрачность 30 процентов на любом расстоянии.

Если выключено, ник может стать полностью прозрачным.
:::

::: details Invert nametag fade direction
По умолчанию: выключено. Доступно, пока включено **Fade nametags in/out**.

Если включено, ники прозрачны рядом с транспортным средством и становятся заметнее по мере удаления от него.

Если выключено, ники видны рядом с транспортным средством и становятся прозрачнее по мере удаления от него.
:::

### Список игроков

::: details Show the player ID's
По умолчанию: включено.

Если включено, в списке игроков появляется дополнительный столбец с ID каждого игрока. ID полезен персоналу сервера.

Если выключено, список игроков показывает только имена и пинг.
:::

::: details Highlight queued players
По умолчанию: включено.

Если включено, игрок с изменениями в очереди выделяется в списке игроков.

Если выключено, игроки не выделяются.
:::

::: details Playerlist left click action
По умолчанию: **Queue events**.

Эта настройка задаёт, что делает щелчок левой кнопкой мыши по имени игрока в списке игроков. Варианты:

- **Queue events**: загружает изменения этого игрока из очереди.
- **Switch camera to**: включает наблюдение за игроком.
- **Open profile**: открывает профиль игрока на форуме.
- **Delete all vehicles**: удаляет весь транспорт игрока в вашей игре.
- **Queue deleted vehicles**: ставит в очередь транспорт игрока, который вы удалили.
- **Copy name**: копирует имя игрока.

Щелчок правой кнопкой мыши по имени всегда открывает меню со всеми этими действиями.
:::

## Игроки {#players}

::: details Show Player names on license plates
По умолчанию: включено.

Если включено, на номерном знаке транспортного средства другого игрока отображается имя этого игрока.

Если выключено, BeamMP не меняет текст номерного знака.
:::

:::: details Fade out vehicles as they get closer
По умолчанию: выключено.

Если включено, транспортные средства других игроков становятся прозрачнее по мере приближения. С расстояния 20 м они полностью видны, а в вашей точке полностью прозрачны. Это работает, только пока отображаются ники.

Если выключено, транспортные средства других игроков остаются полностью видимыми на любом расстоянии.

::: info
Это меняет только внешний вид транспортного средства, а не его физику. Настройка рассчитана на использование с выключенными столкновениями. Соответствующая настройка самой игры находится в параметрах **Игровой процесс**.
:::
::::

::: details Use simplified vehicles when available
По умолчанию: выключено.

Если включено, транспортные средства других игроков заменяются упрощёнными версиями из трафика BeamNG.drive, для тех транспортных средств, у которых такая версия есть. Это снижает точность столкновений и графики и повышает производительность.

Если выключено, игра использует модели транспортных средств, которые выбрал другой игрок.
:::

## Расширенные параметры {#advanced}

::: details Enable vehicle position smoothing
По умолчанию: выключено.

Если включено, BeamMP сглаживает данные о положении игроков с нестабильным соединением. Это уменьшает «телепортацию» и рывки транспортных средств.

Если выключено, BeamMP обновляет положение транспортных средств по мере поступления данных.
:::

:::: details Show network activity in the console
По умолчанию: выключено.

Если включено, сетевая активность BeamMP показывается в консоли.

Если выключено, консоль её не показывает.

::: danger
Вывод консоли также записывается в файлы журнала. При включённой настройке они могут вырасти на сотни мегабайт за несколько минут.
:::
::::

:::: details Launcher port
По умолчанию: 4444.

Это порт, который игра использует для связи с лаунчером. Меняйте его, только если порт 4444 использовать нельзя. Укажите то же число в параметре `Port` в `Launcher.cfg`.

::: tip
Указанный вами порт — первый из двух. Игра использует и следующий порт: для 4444 это 4445. Первый передаёт основные сетевые пакеты, второй — игровые сетевые пакеты.
:::
::::

## Окно чата {#the-chat-window}

Когда включено **New chat menu**, чат — это окно ImGui со своими настройками. Нажмите значок шестерёнки в строке заголовка окна, чтобы открыть их. В них две вкладки, на каждой есть кнопки **Reset to default** и **Save**. Настройки хранятся в `settings/BeamMP/chat.json`.

::: details Вкладка General
**Inactive fade**: по умолчанию включено. Если включено, окно плавно скрывается, когда вы им не пользуетесь.

**Fade time**: по умолчанию 2,5 с, не меньше 0,1 с. Сколько окно ждёт, прежде чем скрыться.

**Fade when collapsed**: по умолчанию выключено. Если включено, окно скрывается и тогда, когда оно свёрнуто.

**Show on message**: по умолчанию включено. Если включено, окно снова появляется, когда приходит сообщение.

**Keep active on Enter**: по умолчанию включено. Если включено, курсор остаётся в поле сообщения после нажатия `Enter`.
:::

::: details Вкладка Theming
Задаёт цвета окна: **Window Background**, **Button Background**, **Button Hovered**, **Button Active**, **Text Color**, **Primary Color** и **Secondary Color**.
:::

Действия клавиш **Bring to Front** и **Toggle Chat** в настройках управления снова показывают окно после того, как оно скрылось, и скрывают его.
