# Serverbetreiber

Alles, was du zum Hosten und Betreiben eines BeamMP-Servers brauchst.

## Hier geht es los

Wähle, wie du hosten möchtest:

- **Zu Hause, auf deinem eigenen Computer.** Das ist kostenlos. Folge der Anleitung [Einen Server hosten](/de/server-owners/host-a-server). Spieler außerhalb deines Zuhauses können nur beitreten, wenn du [einen Port weiterleitest](/de/server-owners/port-forwarding).
- **Auf einem VPS oder bei einem Hosting-Anbieter.** Das ist einfacher und sicherer und erfordert keine Änderungen am Router. Folge der Anleitung [Server-Einrichtung auf einem VPS](/de/server-owners/setup-vps).

## Deinen Server pflegen

- [Server-Konfiguration](/de/server-owners/configuration): die Einstellungen der `ServerConfig.toml`, Servernamen und Tags sowie die Pfade der Standardkarten.
- [Server Wartung](/de/server-owners/maintenance): die Logdatei und das Aktualisieren des Servers.
- [Server Handbuch](/de/server-owners/manual): Umgebungsvariablen, der Resources-Ordner, Kommandozeilenargumente und Limits.
