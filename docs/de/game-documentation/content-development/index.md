# Inhaltsentwicklung

Inhalte für BeamNG.drive sind Karten, Objekte, Fahrzeuge, UI-Apps und Lua-Mods. Ein Mod, den du für das Spiel erstellst, funktioniert auch mit BeamMP, sofern der Server, dem du beitrittst, ihn hat.

Wir haben keine eigenen Anleitungen zum Erstellen von Karten, Objekten oder Fahrzeugen. Die Dokumentation von BeamNG deckt sie ab:

- [Modding](https://documentation.beamng.com/modding/): die Übersicht über alles, was du erstellen kannst.
- [Vehicles](https://documentation.beamng.com/modding/vehicle/): Fahrzeuge erstellen.
- [The World Editor](https://documentation.beamng.com/world_editor/): Karten bauen und bearbeiten.
- [UI](https://documentation.beamng.com/modding/ui/): UI-Elemente erstellen.
- [Programming](https://documentation.beamng.com/modding/programming/): Lua, Erweiterungen und Debugging.

Auf dieser Website:

- [UI-Apps (HTML)](/de/game-documentation/programming/ui-apps-html-cef) zeigt, wie du eine UI-App erstellst.
- [ImGui-Fenster-Tutorial](/de/game-documentation/programming/imgui) zeigt, wie du ein einfaches ImGui-Fenster erstellst.
- Wie du einen Mod auf einen BeamMP-Server bringst, erfährst du unter [Mod- & Ressourcenerstellung](/de/developers/mod-and-resource-creation) und [Mod-Sicherheit](/de/players/mod-safety).
