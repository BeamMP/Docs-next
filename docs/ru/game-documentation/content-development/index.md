# Разработка контента

Контент для BeamNG.drive — это карты, объекты, транспорт, UI-приложения и Lua-моды. Мод, который вы создаёте для игры, работает и с BeamMP, если он есть на сервере, к которому вы подключаетесь.

Собственных руководств по созданию карт, объектов и транспорта у нас нет. Их описывает документация BeamNG:

- [Modding](https://documentation.beamng.com/modding/): обзор всего, что можно создать.
- [Vehicles](https://documentation.beamng.com/modding/vehicle/): создание транспорта.
- [The World Editor](https://documentation.beamng.com/world_editor/): создание и редактирование карт.
- [UI](https://documentation.beamng.com/modding/ui/): создание элементов интерфейса.
- [Programming](https://documentation.beamng.com/modding/programming/): Lua, расширения и отладка.

На этом сайте:

- [UI-приложения (HTML)](/ru/game-documentation/programming/ui-apps-html-cef) показывают, как создать UI-приложение.
- [Руководство по окну ImGui](/ru/game-documentation/programming/imgui) показывает, как создать простое окно ImGui.
- Чтобы добавить мод на сервер BeamMP, читайте [Создание модов и ресурсов](/ru/developers/mod-and-resource-creation) и [Безопасность модов](/ru/players/mod-safety).
