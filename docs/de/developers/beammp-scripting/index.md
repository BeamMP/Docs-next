# BeamMP-Scripting

Referenzen für die Funktionen und Events, die du in BeamMP-Lua-Code verwenden kannst. Um dein erstes Plugin zu schreiben, beginne mit [Mod- & Ressourcenerstellung](/de/developers/mod-and-resource-creation).

- [Mod (Im Spiel)](/de/developers/beammp-scripting/mod-in-game): Funktionen für clientseitige Plugins.
- [Server, Version 3 (aktuell)](/de/developers/beammp-scripting/server/latest): das Server-Plugin-System.
- [Server, Version 2 (veraltet)](/de/developers/beammp-scripting/server/legacy-v2): das alte System, nicht mehr unterstützt. Für Server, die noch auf Version 2 laufen.
