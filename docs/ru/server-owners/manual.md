# Руководство по серверу

Эта страница — справочник по поведению сервера BeamMP. О том, как его настроить, см. [Запуск сервера](/ru/server-owners/host-a-server). О параметрах `ServerConfig.toml` см. [Настройка сервера](/ru/server-owners/configuration).

## Что влияет на сервер

На сервер влияет состояние следующих внешних параметров:

- Папка `Resources`
- Окружение (переменные окружения процесса)
- Аргументы командной строки
- Файл `ServerConfig.toml`
- Рабочий каталог

## Папка Resources

Сервер создаёт папку `Resources` при запуске, с подпапками `Client` и `Server`.

- В `Server` лежат папки, в каждой из которых есть хотя бы один файл `.lua`. Каждая такая папка — «плагин». Сервер загружает плагины в алфавитном порядке без учёта регистра и пропускает всё, что лежит в `Server` и не является папкой. Файлы `.lua` на верхнем уровне плагина перезагружаются на лету при изменении. О том, как писать плагины, см. [справочник по серверному скриптингу](/ru/developers/beammp-scripting/server/latest).
- В `Client` лежат файлы `.zip`, которые игроки скачивают при подключении. Сервер читает их при запуске, а любой файл, который не является `.zip`, пропускает с предупреждением. Чтобы подхватить добавленные, изменённые или удалённые моды во время работы сервера, используйте [консольную команду](#console-commands) `reloadmods`.

Кроме того, в `Client` сервер хранит файл `mods.json`. В нём записаны хеш SHA-256 каждого мода и признак того, защищён ли мод, чтобы сервер не вычислял хеш неизменившегося мода заново. Сервер перезаписывает этот файл по мере необходимости. Не редактируйте его.

## Переменные окружения

### Общие настройки {#general-settings}

Начиная с релиза сервера v3.2.0, сервер принимает переменные окружения, которые **переопределяют** параметры из `ServerConfig.toml`. Такая переменная есть у каждого параметра. Названия параметров записаны в PascalCase. Название переменной — это то же имя ЗАГЛАВНЫМИ_БУКВАМИ, с символом подчёркивания в начале каждого нового слова и с префиксом `BEAMMP_`. Например, `MaxPlayers` превращается в `MAX_PLAYERS`, а с префиксом — в `BEAMMP_MAX_PLAYERS`. Существуют следующие переменные (в столбце «С версии» указан первый релиз сервера, который читает каждую из них):

| Переменная | Параметр | С версии |
|---|---|---|
| `BEAMMP_DEBUG` | `Debug` | v3.2.0 |
| `BEAMMP_PRIVATE` | `Private` | v3.2.0 |
| `BEAMMP_PORT` | `Port` | v3.2.0 |
| `BEAMMP_MAX_CARS` | `MaxCars` | v3.2.0 |
| `BEAMMP_MAX_PLAYERS` | `MaxPlayers` | v3.2.0 |
| `BEAMMP_MAP` | `Map` | v3.2.0 |
| `BEAMMP_NAME` | `Name` | v3.2.0 |
| `BEAMMP_DESCRIPTION` | `Description` | v3.2.0 |
| `BEAMMP_TAGS` | `Tags` | v3.2.0 |
| `BEAMMP_RESOURCE_FOLDER` | `ResourceFolder` | v3.2.0 |
| `BEAMMP_AUTH_KEY` | `AuthKey` | v3.2.0 |
| `BEAMMP_LOG_CHAT` | `LogChat` | v3.2.0 |
| `BEAMMP_ALLOW_GUESTS` | `AllowGuests` | v3.5.0 |
| `BEAMMP_INFORMATION_PACKET` | `InformationPacket` | v3.7.0 |
| `BEAMMP_IM_SCARED_OF_UPDATES` | `ImScaredOfUpdates` (раздел `[Misc]`) | v3.8.2 |
| `BEAMMP_UPDATE_REMINDER_TIME` | `UpdateReminderTime` (раздел `[Misc]`) | v3.8.2 |
| `BEAMMP_IP` | `IP` | v3.8.3 |

Для параметров, которые являются строками или числами, значение — это строка, например `BEAMMP_NAME="Cool Server"`, `BEAMMP_NAME=Server1` или `BEAMMP_PORT=12345`.

Для параметров «истина или ложь» (включено или выключено) значение `true` или `1` означает «включено». Любое другое значение означает «выключено».

Пустая или незаданная переменная игнорируется. Значения, которые сервер в итоге использует, включая эти, он при запуске записывает обратно в `ServerConfig.toml`, если только не задана `BEAMMP_PROVIDER_DISABLE_CONFIG`.

### Настройки провайдера {#provider-settings}

Эти переменные позволяют хостинг-провайдерам и всем, у кого много серверов, переопределять специфичные для провайдера параметры.

#### `BEAMMP_PROVIDER_PORT_ENV` (с v3.3.0 по v3.4.1 и начиная с v3.7.2)

Если задана непустая строка, она указывает имя другой переменной, из которой нужно читать порт вместо `BEAMMP_PORT`. Серверы с v3.5.0 по v3.7.1 её не читают. Например, Pterodactyl может передавать порт в переменной `SERVER_PORT`. Можно задать `BEAMMP_PORT=${SERVER_PORT}`, но проще задать `BEAMMP_PROVIDER_PORT_ENV="SERVER_PORT"`, и сервер будет читать порт из переменной `SERVER_PORT`.

#### `BEAMMP_PROVIDER_IP_ENV` (начиная с v3.8.4)

Если задана непустая строка, она указывает имя другой переменной, из которой нужно читать IP-адрес вместо `BEAMMP_IP`. Работает так же, как `BEAMMP_PROVIDER_PORT_ENV`.

#### `BEAMMP_PROVIDER_DISABLE_CONFIG` (начиная с v3.3.0)

Если задано `1` или `true`, файл `ServerConfig.toml` **не создаётся** и **не читается**, даже если он существует. Чтобы сервер работал, необходимо задать `BEAMMP_AUTH_KEY`.

#### `BEAMMP_PROVIDER_UPDATE_MESSAGE` (начиная с v3.2.2)

Если задана непустая строка, она заменяет всё сообщение об обновлении, которое по умолчанию начинается словами “NEW VERSION IS OUT! Please update to the new…”.

Ваше сообщение **обязательно** должно содержать `{}` в любом месте. Сервер заменит это на номер новой версии. Например:

```sh
BEAMMP_PROVIDER_UPDATE_MESSAGE="NEW VERSION of the BeamMP-Server has been released: {}! Please follow the update guide here: https://example.com/update-guide"
```

Получится такое сообщение об обновлении:

```text
NEW VERSION of the BeamMP-Server has been released: v5.0.2! Please follow the update guide here: https://example.com/update-guide
```

Дайте пользователям понять, что им нужно обновиться, и объясните, как это сделать.

#### `BEAMMP_PROVIDER_DISABLE_MP_SET` (начиная с v3.9.2)

Если задано `1` или `true`, Lua-плагины не могут менять настройки сервера через `MP.Set`. Плагин, который попытается это сделать, получит ошибку о том, что вызов заблокирован вашим провайдером сервера.

#### `BEAMMP_MAX_CONCURRENT_CONNECTIONS` (начиная с v3.9.4)

Задаёт максимальное число подключений, которые сервер принимает одновременно с одного IP-адреса. Это целое число от 1 до 128, по умолчанию 10. Значение вне диапазона или не число игнорируется с предупреждением. Кроме того, сервер принимает не более 128 одновременных подключений в сумме, и это значение изменить нельзя. Команда `status` показывает оба ограничения.

## Аргументы командной строки

Запустите сервер с `--help`, чтобы увидеть их: `./BeamMP-Server --help`. Доступны следующие аргументы:

| Аргумент | Что делает |
|---|---|
| `--help` | Показывает справку и завершает работу |
| `--version` | Выводит версию сервера и завершает работу |
| `--port=1234` | Задаёт порт TCP и UDP, который слушает сервер. Переопределяет окружение и `ServerConfig.toml` |
| `--config=/path/to/ServerConfig.toml` | Абсолютный или относительный путь к файлу конфигурации сервера, включая имя файла. Путь с пробелами берите в кавычки |
| `--working-directory=/path/to/folder` | Задаёт рабочий каталог сервера. Все пути, включая путь в `--config`, отсчитываются от него |

Например, `BeamMP-Server --config=../MyWestCoastServerConfig.toml` запускает сервер с файлом конфигурации, лежащим на одну папку выше.

## Консольные команды {#console-commands}

Вводите их в консоли сервера. Нажмите `Tab`, чтобы дополнить команду.

| Команда | Что делает |
|---|---|
| `help` | Показывает команды |
| `exit` | Завершает работу сервера |
| `kick <name> [reason]` | Выгоняет игрока, причину указывать необязательно. Имя сопоставляется с началом имени игрока без учёта регистра. Если причина не указана, игрок видит «Kicked by server console» |
| `list` | Выводит список всех игроков с их ID и количеством машин |
| `say <message>` | Отправляет сообщение всем игрокам в чат |
| `lua [state id]` | Переключается на консоль Lua, при необходимости в состояние с указанным id. См. [Отладка](/ru/developers/beammp-scripting/server/latest#debugging) |
| `settings [command]` | Задаёт или показывает настройки сервера. Выполните `settings help`, чтобы узнать больше. См. [команда settings](#settings-command) |
| `status` | Показывает, как дела у сервера: игроки, машины, время работы, состояния Lua, таймеры и обработчики событий, ограничения подключений и состояние каждой части сервера |
| `clear` | Очищает окно консоли |
| `version` | Показывает платформу, версию сервера, а также версии Lua и OpenSSL |
| `protectmod <name> <value>` | Задаёт, защищён ли мод. Имя — это имя файла мода вместе с `.zip`. Значение — `true` или `false` |
| `reloadmods` | Перезагружает все моды из папки `Resources/Client` |
| `nettest` | Спрашивает у сервиса проверки серверов BeamMP, могут ли игроки добраться до вашего сервера по его порту, и выводит ответ. В списке `help` её нет. Начиная с v3.8.5 |

Плагин может добавлять собственные команды с помощью события `onConsoleInput`. См. [Собственные команды](/ru/developers/beammp-scripting/server/latest#custom-commands).

### Команда settings {#settings-command}

У `settings` есть четыре подкоманды:

- `settings list` выводит список параметров и их значений.
- `settings get <category> <setting>` выводит одно значение, например `settings get General MaxPlayers`.
- `settings set <category> <setting> <value>` изменяет одно значение, например `settings set General MaxPlayers 12`. Значение с пробелами берите в кавычки.
- `settings help` показывает эти подкоманды.

Изменение действует до остановки сервера. В `ServerConfig.toml` оно не записывается. В разделе `General` можно менять `Description`, `Tags`, `MaxPlayers`, `Name`, `Map`, `MaxCars`, `Debug`, `AllowGuests` и `InformationPacket`, а в разделе `Misc` — `ImScaredOfUpdates` и `UpdateReminderTime`. Параметры `Private`, `IP`, `Port`, `LogChat` и `ResourceFolder` можно только прочитать, но не изменить. `AuthKey` нельзя ни прочитать, ни изменить.

## ServerConfig.toml

Сервер создаёт этот файл при первом запуске. Комментарии внутри файла кратко объясняют каждый параметр, а сервер заново записывает файл при каждом запуске. См. [Настройка сервера](/ru/server-owners/configuration).

Если `AuthKey` пуст, сервер выводит ошибку и закрывается через 10 секунд. То же происходит, если в файле есть ошибка, например пропущена кавычка.

## Рабочий каталог

То, где создаются `ServerConfig.toml`, файлы журнала и папка `Resources`, определяется рабочим каталогом сервера, а не расположением исполняемого файла сервера.

## Ограничения

Бэкенд BeamMP накладывает на серверы следующие ограничения:

- Название: 250 символов
- Описание: 1000 символов
- Карта: 100 символов
- Теги: 100 символов

Сам сервер накладывает такие ограничения:

- Версия лаунчера: игроку, у которого лаунчер старше 2.7.0, отказывают в подключении, и он видит сообщение с указанием нужной версии.
- Сообщения чата: сообщение длиннее 500 байт, а также пустое сообщение отбрасывается.
- Подключения: по умолчанию не более 10 одновременно с одного IP-адреса и 128 в сумме. См. `BEAMMP_MAX_CONCURRENT_CONNECTIONS`.
