# Proprietari di server

Tutto ciò che serve per ospitare e gestire un server BeamMP.

## Da dove iniziare

Scegli come ospitare il server:

- **A casa, sul tuo computer.** È gratuito. Segui [Ospitare un server](/it/server-owners/host-a-server). I giocatori esterni alla tua rete domestica possono entrare solo se fai il [port forwarding](/it/server-owners/port-forwarding).
- **Su un VPS o con una società di hosting.** È più semplice e più sicuro e non richiede modifiche al router. Segui [Configurazione del server su un VPS](/it/server-owners/setup-vps).

## Prenditi cura del tuo server

- [Configurazione del server](/it/server-owners/configuration): le impostazioni di `ServerConfig.toml`, i nomi e i tag dei server e i percorsi delle mappe vanilla.
- [Manutenzione del server](/it/server-owners/maintenance): il file di log e l'aggiornamento del server.
- [Manuale del server](/it/server-owners/manual): variabili d'ambiente, cartella Resources, argomenti da riga di comando e limiti.

## Quando qualcosa non va

- [Verifica CGNAT](/it/server-owners/cgnat): perché nessuno riesce a entrare anche se le porte sono reindirizzate.
- [Codici errore server](/it/server-owners/error-codes): cosa significano i codici nella finestra del Launcher.
- [FAQ del server](/it/server-owners/faq): domande frequenti e problemi noti.
