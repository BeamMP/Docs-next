## Получение AuthKey {#get-an-authkey}

AuthKey, или «ключ аутентификации», нужен, чтобы **публичный** сервер появился в списке серверов. Его также рекомендуется использовать для приватных серверов.

- Количество ключей ограничено. Один ключ одновременно работает только на одном сервере, поэтому запустить два сервера с одним ключом нельзя.
- Дополнительные ключи можно получить, поддержав проект. См. [Как получить ранний доступ?](/ru/players/faq) в FAQ для игроков.
- Вам нужен аккаунт BeamMP. Аккаунт Discord для создания ключа не нужен.

::: warning
Никогда не передавайте свой AuthKey и никому его не показывайте. Относитесь к нему как к паролю.
:::

1. Откройте [BeamMP Accounts](https://accounts.beammp.com) и войдите в систему. Если у вас ещё нет аккаунта, воспользуйтесь инструкцией [Ваш аккаунт BeamMP](/ru/players/account).
2. Нажмите **Keymaster** в меню в верхней части страницы.
3. Нажмите **Create New Server Key**, затем **Create Key**. Новый ключ появится в списке **Your Server Keys**.
4. В разделе **Your Server Keys** нажмите **Show Keys**. Каждый ключ показывается в сокращённом виде (первые 8 и последние 4 символа) вместе с датой создания.
5. Нажмите на значок копирования рядом с ключом. Keymaster скопирует ключ целиком. Сохраните его для следующего шага.

Ключ выглядит так: `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`. В Keymaster нет поля для названия ключа и кнопки для удаления ключа. Неиспользуемый ключ всё равно учитывается в вашем лимите.

### Лимит ключей {#your-key-limit}

В разделе **Your Server Keys** показано, сколько ключей вы уже использовали (например, `1 / 2 keys used`), и откуда взялись дополнительные ключи. По умолчанию:

- У каждого аккаунта может быть 2 ключа.
- Уровень подписки на Patreon добавляет по одному ключу за каждый целый доллар США из его стоимости. Сначала привяжите аккаунт Patreon в BeamMP Accounts. См. [Ваш аккаунт BeamMP](/ru/players/account#linked-accounts).
- Буст сервера BeamMP в Discord даёт 5 ключей в сумме, а не по 5 за каждый буст. Сначала привяжите аккаунт Discord в BeamMP Accounts. Буст может отобразиться не сразу, до суток.

Когда лимит исчерпан, вместо создания ключа **Create New Server Key** показывает сообщение **Key Limit Reached**.

### Замена ключа, который могли увидеть другие {#replace-a-key-that-others-have-seen}

Если ваш ключ мог стать известен кому-то ещё, замените его.

1. В разделе **Your Server Keys** нажмите на значок замены (ротации) рядом с ключом.
2. Нажмите **Rotate Key**. Старый ключ перестанет работать сразу же, а сервер, который его использовал, исчезнет из списка серверов.
3. Скопируйте новый ключ и впишите его в параметр `AuthKey` файла `ServerConfig.toml`.
4. Перезапустите сервер.

Ключ, заблокированный сотрудниками, заменить нельзя.

### Перенос старых ключей в BeamMP Accounts {#move-your-old-keys-to-beammp-accounts}

Ключи, полученные до появления BeamMP Accounts, привязаны к вашему аккаунту Discord.

1. В **Keymaster** найдите блок **Legacy Keys**. Он отображается, только пока есть что делать.
2. Если Discord не привязан, нажмите **Link Discord** и войдите в тот аккаунт Discord, которому принадлежали ключи.
3. Нажмите кнопку **Migrate**, на которой указано количество ключей, и подтвердите действие кнопкой **Migrate Keys**. Каждый ключ сохраняет своё значение, поэтому ваши серверы остаются в сети, и на них ничего менять не нужно.

Перенесённые ключи учитываются в лимите. Если из-за них вы превысите лимит, все ключи останутся у вас, но создавать новые ключи вы не сможете, пока не окажетесь снова в пределах лимита.

Keymaster также показывает серверы, которые сейчас в сети с вашими ключами, в разделе **Your Online Servers**: с количеством игроков и версией.
