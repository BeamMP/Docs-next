# Scripting BeamMP

Références des fonctions et des événements utilisables dans le code Lua de BeamMP. Pour écrire votre premier plugin, commencez par [Création de mods et de ressources](/fr/developers/mod-and-resource-creation).

- [Mod (en jeu)](/fr/developers/beammp-scripting/mod-in-game) : fonctions pour les plugins côté client.
- [Serveur, version 3 (dernière)](/fr/developers/beammp-scripting/server/latest) : le système de plugins serveur.
- [Serveur, version 2 (obsolète)](/fr/developers/beammp-scripting/server/legacy-v2) : l'ancien système, qui n'est plus pris en charge. Pour les serveurs qui utilisent encore la version 2.
