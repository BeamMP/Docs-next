### 我在哪里可以找到代码？

所有源代码都在 [GitHub](https://github.com/BeamMP) 上。这些代码受我们的[使用条款](https://forum.beammp.com/t/terms-of-use-v1-0/43)和以下许可证约束：

| 代码 | 许可证 |
|---|---|
| 服务器 | [LICENSE](https://github.com/BeamMP/BeamMP-Server/blob/master/LICENSE) |
| 启动器 | [LICENSE](https://github.com/BeamMP/BeamMP-Launcher/blob/master/LICENSE) |
| 客户端 Lua | [LICENSE](https://github.com/BeamMP/BeamMP/blob/development/LICENSE) |

### 我发现了 bug 或漏洞，我该怎么办？

如果是代码问题，并且你会使用 GitHub，请在我们 [GitHub](https://github.com/BeamMP) 上相应的仓库中提交一个“Issue”。我们采用以 Issue 为核心的工作流程，所以即使你已经有了修复方案，也请先提交 Issue，再提交一个解决它的“Pull Request”。关于参与贡献的更多信息，请参阅[贡献指南](https://github.com/BeamMP/BeamMP/blob/development/CONTRIBUTING.md)。

如果你没有 GitHub 账号，或者不知道如何使用 GitHub，也可以通过其他方式联系我们：

- 如果内容不敏感，请在 [BeamMP 论坛](https://forum.beammp.com)上发帖，或在 [Discord 服务器](https://discord.gg/beammp)上报告。
- 如果内容敏感，请直接在 [Discord](https://discord.gg/beammp) 上向一名工作人员报告。
