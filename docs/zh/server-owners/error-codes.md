# 服务器错误代码

本页列出了服务器可能显示的错误代码，以及遇到每种错误该怎么办。


| 代码  | 描述                                       | 可能的解决方案                                                                                                        |
|-------|--------------------------------------------|-----------------------------------------------------------------------------------------------------------------------|
| 10022 | 绑定端口时出现问题                         | 检查服务器使用的端口是否已被其他服务占用，如果是，请换一个端口。                                                      |
| 10048 | 地址已被占用                               | 另一个 BeamMP 服务器或程序正在使用该端口，请换一个端口。                                                              |
| 10051 | 网络不可达                                 | 端口转发配置错误或类似问题，请确认所有设置均已正确配置。                                                              |
| 10052 | 网络重置                                   | 在建立连接的过程中网络断开时会发生。请重试连接。                                                                      |
| 10053 | 连接已中止                                 | 由超时或网络错误引起，请重试连接。                                                                                    |
| 10054 | 连接被对端重置                             | 有客户端已从你的服务器断开连接。                                                                                      |
| 10060 | 连接超时                                   | 你的端口转发存在问题，请参阅[端口转发步骤](/zh/server-owners/host-a-server#forward-the-port)。                       |
| 10061 | 连接被拒绝                                 | 你的端口转发存在问题，请参阅[端口转发步骤](/zh/server-owners/host-a-server#forward-the-port)。                       |
| 10064 | 主机已关闭                                 | 这种错误不太可能出现，它表示主机已关闭，原因可能是主机被关机或端口被关闭。                                            |
| 10065 | 无法访问主机                               | 没有网络或端口转发配置错误，请参阅[端口转发步骤](/zh/server-owners/host-a-server#forward-the-port)。                 |

对于不在此列表中的错误代码，如果你对网络和套接字的工作方式有一定了解，可以参阅 [Windows Sockets 错误代码](https://learn.microsoft.com/en-us/windows/win32/winsock/windows-sockets-error-codes-2)。
