# Настройки мультиплеера

Это настройки на странице настроек мультиплеера BeamMP. Каждая из них свёрнута: откройте её, чтобы увидеть, что она делает во включённом и выключенном состоянии. Если вы новичок, начните со страницы [Первичная настройка мультиплеера](/ru/get-started/multiplayer-settings-quickstart).

## Общие

::: details Show advanced options
Если включено, будут видны все настройки мультиплеера

Если выключено, видны только базовые настройки мультиплеера
:::

::: details Enable config cloning protection
Если включено, конфигурация вашего созданного транспортного средства будет защищена от сохранения другими игроками

Если выключено, другие игроки смогут сохранить конфигурацию вашего созданного транспортного средства
:::

:::: details Disable pausing caused by instabilities
Если включено, физические нестабильности не будут ставить вашу игру на паузу

Если выключено, физические нестабильности будут ставить вашу игру на паузу

::: note
Рекомендуется оставить выключенным, так как повторяющиеся нестабильности могут привести к вылету игры
:::
::::

::: details Use simplified vehicles when available
Если включено, игра будет заменять транспортные средства других игроков их упрощёнными версиями (из AI-трафика), если они доступны

Если выключено, игра будет использовать исходные модели транспортных средств
:::

:::: details New chat menu
Если включено, внутриигровой чат будет отображаться в окне [IMGUI](https://github.com/ocornut/imgui), которое, например, можно вынести за пределы игры на другой монитор

Если выключено, внутриигровой чат будет отображаться в UI-приложении

::: note
Вынос окон IMGUI за пределы главного окна игры может снизить производительность, а также сбить программы записи экрана, и они запишут окно чата вместо основного окна игры
:::
::::

::: details Enable vehicle position smoothing
Если включено, BeamMP будет использовать алгоритм, который сглаживает обновления положения транспортных средств через регулярные интервалы. Это может помочь между игроками с высоким пингом или при большой потере пакетов

Если выключено, BeamMP будет обновлять положение транспортных средств по мере получения данных
:::

::: details Skip the mod security warning popups
Если включено, всплывающее окно с предупреждением о безопасности модов не будет показываться при подключении к серверу с модами

Если выключено, это окно будет показываться при каждом подключении к серверу с модами
:::

::: details Enable player vehicle update/edit queuing
Если включено, создание и изменения транспортных средств других игроков будут помещаться в очередь. Подробнее см. в разделе [Очередь событий](#event-queue)

Если выключено, игра будет загружать создание и изменения транспортных средств других игроков мгновенно
:::

::: details Enable automatic part sync
Если включено, детали ваших транспортных средств будут автоматически синхронизироваться с другими игроками через несколько секунд

Если выключено, чтобы отправить синхронизацию другим игрокам, нужно нажать кнопку синхронизации деталей в меню выбора деталей
:::

::: details Disable switching to other players' vehicles
Если включено, при переключении клавишей Tab транспорт других игроков будет пропускаться

Если выключено, при переключении клавишей Tab будут перебираться все созданные транспортные средства
:::

:::: details Fade out vehicles as they get closer
Если включено, другие транспортные средства будут постепенно исчезать по мере приближения

Если выключено, другие транспортные средства будут полностью видимы независимо от расстояния

::: note
Это влияет только на видимую 3D-модель транспортного средства, а не на его физическую сетку узлов и балок (node-beam-mesh). Чтобы также отключить физику, нужно включить `Упрощённая физика столкновений` в настройках игрового процесса
:::
::::

::: details Show the player IDs
Если включено, во внутриигровом списке игроков появится дополнительная колонка с ID каждого игрока. Полезно для разработки и модерации

Если выключено, список игроков будет показывать только колонки с именем игрока и пингом
:::

::: details Allow the serverlist to refresh ingame
Если включено, список серверов будет регулярно обновляться во время игры. Это может вызывать резкие просадки производительности

Если выключено, список серверов будет обновляться только при открытии главного меню
:::

## Очередь событий {#event-queue}

::: details Highlight queued players
Если включено, игроки с событием в очереди будут выделены во внутриигровом списке игроков

Если выключено, игроки не будут выделяться по отдельности
:::

::: details Apply vehicle changes with
Если выбрано `Левая кнопка мыши`, щелчок левой кнопкой мыши по имени игрока в списке игроков загрузит события из очереди. Щелчок правой кнопкой мыши включит наблюдение за этим игроком

Если выбрано `Правая кнопка мыши`, щелчок правой кнопкой мыши по имени игрока в списке игроков загрузит события из очереди. Щелчок левой кнопкой мыши включит наблюдение за этим игроком
:::

::: details Automatically apply queued vehicle changes
Если включено, события из очереди будут загружаться автоматически, когда вы ехали медленнее порога скорости в течение времени, заданного как таймаут

Если выключено, события из очереди будут загружаться только вручную: кнопкой `События` в верхней части экрана или щелчком по имени игрока в списке игроков
:::

::: details Queue apply speed threshold
Эта настройка задаёт порог скорости для автоматической загрузки событий из очереди. Чтобы события из очереди загрузились, ваше транспортное средство должно двигаться медленнее этого порога дольше, чем `Queue apply timeout`
:::

::: details Queue apply timeout
Эта настройка задаёт задержку по времени для автоматической загрузки событий из очереди. Чтобы события из очереди загрузились, ваше транспортное средство должно двигаться медленнее, чем `Queue apply speed threshold`, в течение этого времени
:::

::: details Skip queue if spectating others
Если включено, событие будет загружено мгновенно, если вы наблюдаете за другим игроком

Если выключено, событие будет помещено в очередь так же, как если бы вы управляли собственным транспортным средством
:::

::: details Don't queue Unicycles (Snowmen/Beamlings)
Если включено, событие, связанное со снеговиком или бимлингом, будет загружено мгновенно

Если выключено, снеговики и бимлинги будут помещаться в очередь так же, как и другие транспортные средства
:::

## Юницикл по умолчанию

::: details Default Unicycle config
Эта настройка задаёт вариант юницикла, который загружается по умолчанию. Можно выбрать готовые конфигурации или свои, если вы сохраняли пользовательские конфигурации юницикла
:::

::: details Automatically save your last used Unicycle
Если включено, последний использованный вами юницикл будет автоматически сохраняться и загружаться при его следующем создании

Если выключено, каждый раз будет создаваться юницикл с конфигурацией по умолчанию
:::

## Капли

::: details Enable blobs for unspawned vehicles
Если включено, вместо ещё не созданного транспортного средства вы увидите шар-заменитель, или каплю

Если выключено, ещё не созданное транспортное средство будет невидимым
:::

:::: details Tune colors
::: details Visible
Если включено, капля будет отображаться выбранным ниже цветом

Если выключено, для указанного случая капля отображаться не будет
:::

::: details RGB HEX values
Транспорт в очереди: цвет капли для транспортного средства, стоящего в очереди на создание. Стандартное значение #FF6400

Недопустимый транспорт: цвет капли для недопустимого транспортного средства, например из мода, загруженного в обход сервера. Стандартное значение #000000

Удалённый транспорт: цвет капли для транспортного средства, удалённого пользователем. Стандартное значение #333333
:::
::::

## Ники

::: details Hide player nametags
Если включено, ники игроков не будут отображаться

Если выключено, ники игроков будут отображаться в зависимости от положения их транспортных средств
:::

::: details Show distance from other players
Если включено, перед ником будет добавлено расстояние до соответствующего транспортного средства

Если выключено, расстояние в нике показываться не будет
:::

::: details Fade nametags in/out
Если включено, ники будут появляться и исчезать в соответствии с настройками `Дистанция исчезновения ников` и `Инвертировать направление исчезновения`

Если выключено, ники будут отображаться с обычной непрозрачностью независимо от расстояния до соответствующего транспортного средства
:::

:::: details Fade distance/Invert nametag fade direction
::: details Fade out
Ники становятся менее заметными по мере удаления игрока

`Дистанция исчезновения ников` задаёт расстояние, на котором ник отображается с минимальной непрозрачностью
:::

::: details Fade in
Ники становятся более заметными по мере удаления игрока

`Дистанция исчезновения ников` задаёт расстояние, на котором ник отображается с максимальной непрозрачностью
:::
::::

::: details Don't fully hide nametags
Если включено, ник не может стать полностью невидимым: он сохраняет минимальную непрозрачность независимо от расстояния

Если выключено, ники могут стать полностью невидимыми
:::

::: details Shorten nametag and role tags
Если включено, `Лимит длины ника` обрежет ники и роли до заданного числа символов

Если выключено, ники и метки ролей будут показываться полностью
:::

::: details Show spectators' nametag under vehicle nametags
Если включено, имя наблюдателя будет добавлено под ником игрока

Если выключено, имена наблюдателей в никах добавляться не будут
:::

::: details Same color for spectator nametags
Если включено, имя наблюдателя всегда будет на сером фоне

Если выключено, имя наблюдателя будет на цветном фоне, соответствующем роли наблюдателя
:::

## Другие настройки

:::: details Show network activity in the console
Если включено, сетевая активность BeamMP будет показываться в консоли

Если выключено, дополнительная сетевая активность в консоли показываться не будет

::: danger
Будьте осторожны с этой настройкой: весь вывод консоли также записывается в файлы журнала

При включённой настройке они могут вырасти на сотни мегабайт за несколько минут
:::
::::

:::: details Launcher port
Эта настройка задаёт порт, который используется для связи с лаунчером

Менять её нужно только в том случае, если стандартный порт 4444 использовать нельзя

Не забудьте также изменить порт на стороне лаунчера, отредактировав `Launcher.cfg`

::: tip
Указанный порт — только первый из двух. Второй порт идёт сразу за ним: порт + 1

Первый порт передаёт основные сетевые пакеты, второй — игровые сетевые пакеты, оба по TCP
:::
::::
