## Получение AuthKey

AuthKey, или «ключ аутентификации», нужен, чтобы **публичный** сервер появился в списке серверов. Его также рекомендуется использовать для приватных серверов.

- Количество ключей ограничено. Один ключ одновременно работает только на одном сервере, поэтому запустить два сервера с одним ключом нельзя.
- Дополнительные ключи можно получить, поддержав проект. См. [Как получить ранний доступ?](/ru/players/faq) в FAQ для игроков.
- Для этого нужен аккаунт [Discord](https://discord.com). Это защищает от спама.

::: warning
Никогда не передавайте свой AuthKey и никому его не показывайте. Относитесь к нему как к паролю.
:::

1. Войдите в [Keymaster](https://keymaster.beammp.com) через Discord, затем нажмите **Keys** в левой части экрана.

   ![Главная страница Keymaster, в меню слева пункт Keys](../../assets/content/keymaster_homepage.png)

2. Нажмите зелёную кнопку **+** в правом верхнем углу.

   ![Страница Keys с зелёной кнопкой плюс в правом верхнем углу](../../assets/content/keymaster_new_key.png)

3. Заполните поле **Server Name** и нажмите **Create**. Это лишь название ключа, а не название, которое ваш сервер показывает в списке серверов. Например:

   ![Форма нового ключа с заполненным названием сервера](../../assets/content/keymaster_server_name.png)

   После этого ключ выглядит примерно так:

   ![Готовый ключ в списке ключей](../../assets/content/keymaster_key_done.png)

4. Скопируйте текст из поля **Key**, нажав на значок буфера обмена справа от ключа. В этом примере ключ — `3173a2e-6az0-4542-a3p0-ddqq5ff95558`. Сохраните его для следующего шага.

   ![Значок буфера обмена рядом с ключом](../../assets/content/keymaster_copy_key.png)
