# Defender / 防火墙排除项

本指南介绍如何在 Windows Defender 防火墙和防病毒软件中，为 BeamMP 启动器和服务器创建排除项。

在修改防火墙之前，如果你处于专用网络中，请先确保在 Windows 网络设置中把你的网络设置为**专用**。

::: danger 排除项存在风险
创建排除项，即表示你了解允许程序在你的电脑上运行、并向公众开放家庭网络端口所带来的风险。因此，你放弃就可能发生在你或你家人身上的任何及一切损失追究 BeamMP 责任的权利。

对于外部链接的服务或网站上的任何内容，我们概不负责。
:::

## 让启动器通过防火墙

1. 打开 **高级安全 Windows Defender 防火墙**。
2. 点击 **入站规则**。
3. 点击右上角的 **新建规则**。
4. 选择 **程序**，为程序创建规则。
5. 输入 `BeamMP-Launcher.exe` 的完整路径。默认路径为 `%appdata%\BeamMP-Launcher\BeamMP-Launcher.exe`，不要加引号。
6. 选择允许连接。
7. 为规则起一个名称，例如“BeamMP-Launcher”，然后保存。
8. 重启电脑。

## 让服务器通过防火墙

1. 打开 **高级安全 Windows Defender 防火墙**。
2. 点击 **入站规则**。
3. 点击右上角的 **新建规则**。
4. 选择 **端口**，为端口创建规则。
5. 输入与 `ServerConfig.toml` 中相同的端口。
6. 输入 `BeamMP-Server.exe` 的完整路径。它就在你下载后放置该文件的位置。
7. 选择允许连接。
8. 为规则起一个名称，例如“BeamMP-Server”，然后保存。
9. 重启电脑。

## 添加防病毒排除项

这适用于启动器和服务器。

1. 打开 **Windows 安全中心** 应用。
2. 点击 **病毒和威胁防护**。
3. 在 **病毒和威胁防护设置** 下，点击 **管理设置**。
4. 向下滚动到 **排除项**。
5. 点击 **添加或删除排除项**，再点击 **添加排除项**，然后选择 **进程**。
6. 输入 `BeamMP-Launcher.exe` 或 `BeamMP-Server.exe`，然后保存。
7. 重启电脑。
