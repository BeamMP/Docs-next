# 模组安全

BeamMP 服务器可以向你的游戏发送模组。本页说明在此之前你会看到的警告、本地模组为什么会导致 BeamMP 无法使用，以及修复方法。

## 模组安全警告 {#the-mod-security-warning}

当你连接到带有模组的服务器时，BeamMP 会在下载任何内容之前显示 **检测到服务器模组** 窗口。它会告诉你：

- 服务器的模组会被自动下载并安装。
- 模组可能包含会在你的电脑上运行的代码，这些代码可能有害。
- 在继续之前，你必须信任服务器所有者，并且继续操作的风险由你自己承担。
- BeamMP 不对服务器发送的内容负责。

点击 **下载并加入** 即可下载模组并加入服务器。点击 **取消并返回** 则不进入该服务器。

如果你信任自己加入的服务器，可以用 **跳过模组安全警告弹窗** 关闭这个警告，详见[多人模式设置](/zh/players/multiplayer-settings)。没有模组的服务器不会显示该警告。

## 为什么我必须停用或移除我的模组？

在 BeamMP 中，你所连接的服务器会提供所需的模组。这些模组会在连接时自动下载并启用，离开服务器时再从游戏中移除。

在会话期间，BeamMP 会停用服务器没有发送的所有模组。例外的是 `multiplayerbeammp`、`beammp` 和 `translations`。即使除了 BeamMP 之外你只多装了一个本地模组，它仍然可能造成问题，例如当它修改了游戏文件时。当你离开发送过模组的服务器时，游戏会重新加载它的 Lua。

使用 BeamMP 时，有四种方法可以修复由模组引起的问题。

### 停用模组

在加入任何服务器之前，请确保除了 `multiplayerbeammp` 之外，没有启用其他任何模组。如果这个方法不起作用，例如游戏卡死或显示黑屏，或者你仍然有问题，请尝试下一种修复方法。

### 新建用户文件夹

这会为游戏提供一个干净的用户文件夹。

1. 关闭 BeamNG.drive。
2. 打开 BeamNG 启动程序，点击 **Manage User Folder**，然后点击 **Open user folder**。
3. 重命名 `current` 文件夹，例如改为 `current_old`。

![三个步骤：BeamNG 启动程序中的 Manage User Folder、Open user folder，然后重命名 current 文件夹](../../assets/content/new-userfolder.png)

游戏下次启动时，会创建一个新的、干净的用户文件夹。

::: warning 我的设置和配置不见了！我怎样才能恢复它们？
如果你重命名了用户文件夹，就等于强制游戏创建了一个新的、干净的用户文件夹。你可以把被重命名的文件夹（例如 `current_old`）中的 `settings` 和 `vehicles` 文件夹复制到新文件夹中。
请确保 BeamNG.drive 已关闭，并替换目标文件夹中的所有项目。这样你应该就能恢复所有配置和设置，与之前一模一样。
:::

::: warning 将文件移回新的用户文件夹时请务必小心。
如果你是通过重命名用户文件夹解决了问题，那么把旧文件移回去，可能会使问题再次出现。
:::

完成后，请通过 BeamMP 启动器启动 BeamNG.drive，这时 `multiplayerbeammp` 应该是 **模组资源库** > **模组管理器** 中唯一已启用的模组，**更多……** 菜单中也会有 **BeamMP** 条目。
如果你在加入带有模组的服务器时仍然有问题，那很可能是该服务器发送了损坏或过时的模组。

### 清除启动器缓存

启动器会把它下载的模组保存在缓存中。要清除缓存，请打开 BeamMP 启动器的安装文件夹，缓存就是其中的 `Resources` 文件夹。如果 `Launcher.cfg` 中有 `CachingDirectory` 条目，缓存就在该条目指定的文件夹中。

删除该文件夹即可删除所有缓存的模组。如果你需要更多磁盘空间，或想清理过时的模组，这会很有帮助。下次你加入需要这些模组的服务器时，启动器会重新下载它们。

### 移除 content 文件夹中的模组

如果你把模组放进了 `content` 文件夹，就应该将它们移除。打开 BeamNG.drive 的安装文件夹，右键点击 `content` 文件夹并将其删除。然后通过 Steam 或 Epic Games 验证游戏文件，这会重新下载基础文件。

::: quote DO_NOT_INSTALL_MODS_HERE.txt
请勿将模组复制到此文件夹：这可能导致模组损坏、更新安装变慢、模组管理器损坏、安全模式损坏等问题。
:::
