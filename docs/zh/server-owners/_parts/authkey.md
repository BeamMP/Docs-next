## 获取 AuthKey

AuthKey 也称为“身份验证密钥”（Authentication Key），它能让**公开**服务器出现在服务器列表中。私人服务器也建议使用。

- 你拥有的密钥数量有限。一个密钥同一时间只能用于一个服务器，所以你不能用同一个密钥运行两个服务器。
- 你可以通过支持本项目来获得更多密钥。请参阅玩家常见问题中的[我如何获得抢先体验资格？](/zh/players/faq)。
- 你需要一个 [Discord](https://discord.com) 账号，这是为了防止垃圾信息。

::: warning
切勿与任何人分享你的 AuthKey，也不要给任何人看。请像对待密码一样对待它。
:::

1. 使用 Discord 登录 [Keymaster](https://keymaster.beammp.com)，然后点击屏幕左侧的 **Keys**。

   ![Keymaster 主页，左侧菜单中有 Keys](../../assets/content/keymaster_homepage.png)

2. 点击右上角的绿色 **+** 按钮。

   ![Keys 页面，右上角有绿色加号按钮](../../assets/content/keymaster_new_key.png)

3. 填写 **Server Name** 字段，然后点击 **Create**。这只是密钥的名称，不是你的服务器在服务器列表中显示的名称。例如：

   ![已填写服务器名称的新建密钥表单](../../assets/content/keymaster_server_name.png)

   随后密钥看起来大致如下：

   ![密钥列表中已创建好的密钥](../../assets/content/keymaster_key_done.png)

4. 点击密钥右侧的剪贴板图标，复制 **Key** 字段中的文本。在这个例子中，密钥是 `3173a2e-6az0-4542-a3p0-ddqq5ff95558`。请保留它，下一步会用到。

   ![密钥旁边的剪贴板图标](../../assets/content/keymaster_copy_key.png)
