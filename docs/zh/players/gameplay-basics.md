# 玩法基础

本页介绍在 BeamMP 服务器上游玩时，BeamNG.drive 有哪些不同之处。每一部分背后的设置见[多人模式设置](/zh/players/multiplayer-settings)。

## 服务器列表

登录后，BeamMP 菜单会打开服务器列表。左侧的按钮决定列表显示什么内容：

- **Public Servers**：所有服务器。官方服务器排在最前面。
- **Official Servers**、**Featured Servers** 和 **Partner Servers**：只显示具有相应身份的服务器。
- **Favorites**：你用 **添加收藏夹** 添加的服务器。
- **Recent**：你最近连接过的 50 个服务器，最新的排在最前面。**清除最近记录** 会清空这个列表。
- **Direct Connect**：通过地址直接连接服务器。

要查找服务器：

- 在搜索框中输入内容，匹配服务器名称。
- 点击列标题（**Location**、**Title**、**Map** 或 **Players**）进行排序。再次点击可以反转顺序。
- 使用 **Search Filters**，按玩家数量（**仅无玩家**、**有玩家的**、**未满**，或用 **Advanced Player Count** 设置最小和最大值）、**总模组大小**、标签、服务器版本、服务器位置和地图来缩小列表范围。开启 **匹配所有筛选条件** 后，服务器必须具有你选择的每一个标签。**重设筛选器** 会清除这些筛选条件。
- 点击 **Refresh** 重新加载列表。

点击一个服务器可以查看它的详细信息：所有者、地图、描述、标签、服务器上的玩家，以及它的模组和 **文件总大小:**。点击 **Connect** 加入服务器。**添加收藏夹** 和 **删除收藏夹** 用来更改你的收藏夹。

在 **Direct Connect** 中，输入 **Server IP** 和 **Server 端口**，或点击 **Paste from Clipboard**，粘贴 `ip:port` 形式的地址。如果留空，BeamMP 会使用 `127.0.0.1` 和端口 `30814`。点击 **Connect** 加入服务器，点击 **保存到收藏夹** 把它加入你的收藏夹。

连接时，**连接到服务器中...** 会显示进度，包括每个正在下载的模组。点击 **Cancel** 可以停止。如果服务器带有模组，你会先看到模组安全警告，详见[模组安全](/zh/players/mod-safety#the-mod-security-warning)。

## 会话栏

在会话中，屏幕顶部的 **BeamMP Session** HUD 应用会显示服务器名称、**Players** 的数量、以 ms 为单位的 **Ping**，以及一个 **Leave** 按钮。点击 **Leave** 会断开连接并返回主菜单。当有更改在等待加载时，会出现 **Events queued** 按钮，详见[事件队列](#the-event-queue)。

暂停菜单中还有一个 **BeamMP** 选项卡。**Player List** 会显示每位玩家及其延迟，并提供复制名称和打开该玩家个人资料的按钮。**Server Details** 会显示服务器的信息。服务器地址在你点击 **Reveal** 之前是隐藏的。

如果服务器将你移除，会有一条消息显示原因，并提供 **返回至菜单** 和 **继续离线模式**。

## 玩家列表

**BeamMP Player List** HUD 应用会显示每位玩家的名称和延迟。在你点击它的箭头按钮（**<** 或 **>**）之前，它是隐藏的，再次点击同一个按钮可以将其隐藏。**↔** 和 **↕** 可以在其框架内左右和上下移动列表。如果 **显示玩家ID** 已开启，列表中还会多出一列，显示每位玩家的 ID。当 **高亮显示排队队列中的玩家** 开启时，有排队更改的玩家会被高亮显示。

当玩家拥有角色时，名称后面会跟着一个角色标签，例如 `[EA]`。角色标签的说明见[昵称标签](#nametags)。

点击名称会执行你在 **玩家列表左键操作** 中选择的操作。默认值是 **事件队列**。右键点击名称会打开一个菜单，包含以下操作：

- **复制昵称**
- **删除所有车辆**：在你的游戏中删除该玩家的车辆。
- **事件队列**
- **切换摄像机至**：观战该玩家。
- **打开配置**：打开该玩家的论坛个人资料。
- **删除车辆队列**：找回你已删除的该玩家的车辆。

模组可以在这个菜单中添加它们自己的按钮。

## 昵称标签 {#nametags}

每位玩家的车辆上方都有一个昵称标签。标签上带有角色标签，还可以带有距离，以及正在观战该车辆的玩家的名称。你可以隐藏昵称标签、让它们随距离淡出，也可以显示距离。**Player Nametags** 按键操作可以隐藏和显示所有昵称标签。

标签由玩家 BeamMP 账号的角色决定：

| 标签 | 简短标签 |
|---|---|
| `[Early Access]` | `[EA]` |
| `[Contributor]` | `[CO]` |
| `[Content Creator]` | `[CC]` |
| `[Events Team]` | `[Events]` |
| `[Support]` | `[Staff]` |
| `[BeamMP Staff]` | `[Staff]` |
| `[Moderator]` | `[Mod]` |
| `[Admin]` | `[Adm]` |
| `[BeamMP Dev]` | `[Dev]` |
| `[BeamNG Developer]`、`[BeamNG Staff]`、`[BeamNG Affiliate]` | `[BNG]` |

没有角色的玩家没有标签。服务器也可以为玩家或车辆设置它自己的标签。

## 聊天

聊天默认显示在 **BeamMP Chat** HUD 应用中。在输入框中输入内容，然后用 **Send** 发送。一条消息最多可以有 500 个字符。在输入框中按 `↑` 可以调出你的上一条消息。消息会在几秒钟后淡出，把鼠标移到聊天上时会重新出现。**↔** 和 **↕** 可以移动聊天。

当 **新聊天菜单** 开启时，聊天会显示在一个可以拖出游戏的独立窗口中。它的设置请参阅[聊天窗口](/zh/players/multiplayer-settings#the-chat-window)。

## 其他玩家的车辆

- 其他玩家的车辆会出现在你的游戏中，他们对零件的更改也会同步给你。当 **启用自动部件同步** 开启时，你自己对零件的更改会在你最后一次更改约 15 秒后自动发送给其他玩家。
- 切换车辆时可以跳过其他玩家的车辆。为此请开启 **禁用切换至其他玩家车辆**。其他玩家的独轮车始终会被跳过。
- 如果你从自己的独轮车切换到其他玩家的车辆，摄像机会进入乘客视角。
- 尚未为你刷出的车辆会显示为一个彩色的球体，称为斑点（blob）。请参阅[斑点](/zh/players/multiplayer-settings#blobs)。
- 如果玩家刷出的车辆使用了你没有的模组，BeamMP 会跳过它并显示一条消息。这辆车会保持为斑点。
- 当 **在车牌上显示玩家名称** 开启时，车牌上会显示拥有该车辆的玩家的名称。
- 为保护你的作品，请开启 **启用配置克隆保护**。这样其他玩家就无法克隆或保存你的车辆，他们会看到 **车辆克隆错误** 或 **车辆保存错误**。

## 事件队列 {#the-event-queue}

当其他玩家刷出或编辑车辆时，你的游戏可以把这些更改放入队列，而不是立即加载，这样加载就不会打断你的驾驶。会有一条消息告诉你有更改已排队，会话栏中也会出现 **Events queued** 按钮。按钮上先显示等待中的刷出数，再显示等待中的编辑数，例如 `2|1`。

排队的更改会在你进行以下操作时加载：

- 点击 **Events queued**。
- 按下你绑定给 **Queue Events** 的按键。
- 点击某位玩家的名称，或在该玩家的菜单中选择 **事件队列**。这只会加载该玩家的更改。

当你低速行驶足够长时间后，它们也会自动加载；如果你没有车辆，则会立即加载。请参阅[事件队列设置](/zh/players/multiplayer-settings#event-queue)。

## 不稳定的车辆

在会话中，物理不稳定不会导致游戏暂停。BeamMP 会转而重置不稳定车辆的物理状态。这适用于会话中的任何车辆，无论是你的还是其他玩家的。

如果同一辆车反复变得不稳定，BeamMP 会先把它暂时关闭并显示一条警告，然后再重新开启。如果在那之后它仍然反复不稳定，这辆车就会被删除，并有一条消息告知你。要找回其他玩家的车辆，请在玩家列表中右键点击该玩家，然后选择 **删除车辆队列**。

## 按键操作

在控制设置中，**BeamMP** 类别包含以下操作。请把它们绑定到你想要的按键上：

| 操作 | 作用 |
|---|---|
| **Bring to Front** | 在聊天窗口淡出后让它重新显示 |
| **Player Nametags** | 显示或隐藏所有玩家的昵称标签 |
| **Queue Events** | 加载所有排队的更改 |
| **Toggle Chat** | 显示或隐藏聊天窗口 |

## 带有模组的服务器

当你连接到带有模组的服务器时，BeamMP 会先显示模组安全警告。接受之前，请先阅读[模组安全](/zh/players/mod-safety)。
