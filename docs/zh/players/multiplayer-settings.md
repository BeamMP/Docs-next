# 多人模式设置

这些是 BeamNG.drive 选项中 **BeamMP** 页面上的设置，对应 BeamNG.drive 0.39 搭配 BeamMP 4.22。要打开它们，请点击 **选项**，然后选择 **BeamMP**。所有设置始终可见：没有用来隐藏高级设置的开关。

下面每一项设置都是一个折叠的条目。展开后可以看到它的默认值，以及它在开启和关闭时分别有什么作用。各个标题对应页面上的分组：**普通**、**Vehicle Update Queue**、**Blobs**、**用户界面**、**玩家** 和 **高级**。如果你是新手，请先看[首次多人模式设置](/zh/get-started/multiplayer-settings-quickstart)。

## 普通 {#general}

::: details 启用配置克隆保护
默认值：关闭。

如果启用，其他玩家无法克隆或保存你的车辆。他们尝试时会看到 **车辆克隆错误** 或 **车辆保存错误**。更改此设置时，也会同步更新你已经刷出的车辆。

如果禁用，其他玩家可以克隆和保存你的车辆。
:::

::: details 禁用切换至其他玩家车辆
默认值：关闭。

如果启用，只要你有自己的车辆，切换车辆时就会跳过其他玩家的车辆。

如果禁用，切换车辆时会循环切换每一辆已刷出的车辆。

无论此设置如何，其他玩家的独轮车始终会被跳过。
:::

::: details 自动保存您上次使用的独轮车
默认值：开启。

如果启用，BeamMP 会在你删除独轮车时保存它的配置，并在你下次刷出独轮车时使用该配置。

如果禁用，删除独轮车时不会保存它的配置。
:::

## 事件队列 {#event-queue}

在游戏中，这个分组名为 **Vehicle Update Queue**。当其他玩家刷出或更改车辆时，BeamMP 可以把这些更改放入队列，而不是立即加载，这样加载就不会打断你的驾驶。

更改在等待期间，会有一条消息告诉你有多少项，屏幕顶部的会话栏上还会显示一个 **Events queued** 按钮。按钮上的两个数字依次是等待中的刷出数和等待中的编辑数。只有队列中有内容时才会显示这个按钮。如果你没有车辆，排队的更改会立即加载。

排队的更改会在以下情况加载：

- 你点击屏幕顶部的 **Events queued**。
- 你按下绑定给 **Queue Events** 的按键。请在控制设置的 **BeamMP** 类别中绑定它。
- 当 **玩家列表左键操作** 设为 **事件队列** 时，你点击某位玩家的名称。这只会加载该玩家的更改。在该玩家的右键菜单中选择 **事件队列** 效果相同。
- 下面所述的自动加载开始。

::: details 启用玩家车辆更新/编辑排队处理
默认值：开启。

如果启用，其他玩家的车辆刷出和编辑会在队列中等待，直到上述某个操作把它们加载进来。

如果禁用，其他玩家的车辆刷出和编辑会立即加载。
:::

::: details 自动应用排队中的车辆更改
默认值：开启。仅在启用排队处理时显示。

如果启用，当你的车辆速度在 **队列应用超时时间** 所设定的时长内一直不高于 **队列应用速度限制** 时，排队的更改就会加载。

如果禁用，排队的更改只会在你自己加载时才加载。
:::

::: details 队列应用速度限制
默认值：2 m/s。滑块范围为 0 至 10 m/s。仅在启用自动加载时显示。

你的车辆必须在 **队列应用超时时间** 所设定的时长内一直不高于此速度，排队的更改才会加载。
:::

::: details 队列应用超时时间
默认值：3 s。滑块范围为 0 至 20 s。仅在启用自动加载时显示。

你的车辆必须在这段时间内一直不高于 **队列应用速度限制**，排队的更改才会加载。
:::

::: details 启用自动部件同步
默认值：开启。

如果启用，你对车辆部件所做的更改会在你最后一次更改约 15 秒后发送给其他玩家。

如果禁用，你的部件更改不会自动发送。
:::

::: details 观战其他玩家时跳过队列
默认值：关闭。

如果启用，当你所在的车辆不是你自己的车辆时，排队的更改会立即加载。

如果禁用，排队的更改会在队列中等待，就像你操控自己的车辆时一样。
:::

::: details 不要将独轮车（雪人/Beamlings）加入队列
默认值：开启。

如果启用，其他玩家的独轮车刷出和编辑会立即加载。

如果禁用，独轮车会和其他车辆一样被放入队列。
:::

## Blobs {#blobs}

斑点（blob）是一个彩色的球体，用来代替尚未为你刷出的车辆。它有四种颜色：

- 排队颜色：车辆正在队列中等待。
- 非法颜色：由于缺少该车辆的模组，车辆无法刷出。
- 已删除颜色：你删除了这辆车。要把它找回来，请在玩家列表中右键点击它的所有者，然后选择 **删除车辆队列**。
- 洋红色：其他任何尚未刷出的车辆。你无法更改这种颜色。

::: details 为未生成的车辆启用 Blobs
默认值：开启。

如果启用，你会看到一个斑点来代替每辆尚未刷出的车辆。

如果禁用，尚未刷出的车辆是不可见的。
:::

::: details 排队中的车辆
默认值：显示，`#FF6400`。

复选框 **排队中的车辆** 用来开启或关闭队列中车辆的斑点。字段 **HEX 颜色值（例如：#FF6400）** 用来设置它的颜色。
:::

::: details 不允许的车辆
默认值：显示，`#000000`。

复选框 **不允许的车辆** 用来开启或关闭无法刷出的车辆的斑点。字段 **HEX 颜色值（例如：#FF6400）** 用来设置它的颜色。
:::

::: details 已删除车辆
默认值：显示，`#333333`。

复选框 **已删除车辆** 用来开启或关闭你已删除的车辆的斑点。字段 **HEX 颜色值（例如：#FF6400）** 用来设置它的颜色。
:::

## 用户界面 {#user-interface}

::: details 跳过模组安全警告弹窗
默认值：关闭。

如果启用，连接到带有模组的服务器时不会显示模组安全警告，模组会直接下载，不会再询问你。

如果禁用，每次连接到带有模组的服务器时都会显示该警告。请参阅[模组安全](/zh/players/mod-safety#the-mod-security-warning)。
:::

::: details 允许在游戏内刷新服务器列表
默认值：关闭。

如果启用，你在会话中时也可以刷新服务器列表。这可能会导致卡顿。

如果禁用，在你离开会话之前，服务器列表会一直显示你加入之前的列表。
:::

::: details HUD App 风格
默认值：**旧版**。可选项为 **旧版** 和 **重新设计**。

此设置决定 BeamMP HUD 应用的外观：会话栏、玩家列表和聊天。
:::

:::: details 新聊天菜单
默认值：关闭。

如果启用，游戏内聊天将显示在一个 [ImGui](https://github.com/ocornut/imgui) 窗口中，你可以把它从游戏中拖出，放到另一台显示器上。请参阅[聊天窗口](#the-chat-window)。

如果禁用，游戏内聊天将显示在 **BeamMP Chat** HUD 应用中。

::: warning
将 ImGui 窗口拖出游戏主窗口可能会导致性能问题，还可能让屏幕录制软件录下聊天窗口，而不是游戏画面。
:::
::::

### 名称标签 {#nametags}

当 **隐藏玩家的名称标签** 开启时，其他昵称标签设置不可用。

::: details 隐藏玩家的名称标签
默认值：关闭。

如果启用，不会绘制任何昵称标签。

如果禁用，每位玩家的昵称标签会绘制在其车辆上方。控制设置中的 **Player Nametags** 按键操作可以隐藏和显示所有昵称标签，直到你重启游戏为止。
:::

::: details 显示与其他玩家的距离
默认值：开启。

如果启用，当车辆在 10 m 以外时，昵称标签末尾会显示与该车辆的距离。距离使用游戏的单位制。

如果禁用，昵称标签不显示距离。
:::

::: details 物体遮挡时隐藏名称标签
默认值：关闭。

如果启用，位于建筑物等物体后面的昵称标签会被这些物体遮住。

如果禁用，昵称标签会绘制在所有物体之上。
:::

::: details 缩短名称标签和角色标签
默认值：关闭。

如果启用，过长的名称会被截断到 **名称标签长度限制**，角色标签则使用其简短形式，例如用 `[EA]` 代替 `[Early Access]`。

如果禁用，名称和角色标签会完整显示。
:::

::: details 名称标签长度限制
默认值：32。滑块范围为 0 至 50。仅在 **缩短名称标签和角色标签** 开启时可用。

这是名称最多显示的字符数。如果名称超出限制三个以上字符，就会被截断到限制长度，并以 `...` 结尾。
:::

::: details 在车辆名称标签下方显示观战者名称标签
默认值：开启。

如果启用，正在观战某辆车的玩家的名称会显示在该车辆昵称标签的下方。

如果禁用，不会显示观战者。
:::

::: details 观战者名称标签使用相同颜色
默认值：关闭。仅在 **在车辆名称标签下方显示观战者名称标签** 开启时可用。

如果启用，所有观战者昵称标签都使用相同的灰色背景。

如果禁用，观战者昵称标签的背景会体现该观战者的角色。
:::

::: details 名称标签淡入淡出
默认值：关闭。

如果启用，昵称标签会根据与其车辆的距离淡入淡出，并使用 **渐隐距离**。**反转名称标签淡入淡出方向** 决定它朝哪个方向淡化。

如果禁用，无论距离多远，昵称标签都以完全不透明的状态绘制。
:::

::: details 渐隐距离
默认值：40 m。滑块范围为 0 至 1500 m。仅在 **名称标签淡入淡出** 开启时可用。

昵称标签在车辆旁边时完全可见，在这个距离处完全透明。如果开启了 **反转名称标签淡入淡出方向**，则正好相反。
:::

::: details 不要完全隐藏名称标签
默认值：关闭。仅在 **名称标签淡入淡出** 开启时可用。

如果启用，无论距离多远，昵称标签都会保留 30% 的最低不透明度。

如果禁用，昵称标签可以变得完全透明。
:::

::: details 反转名称标签淡入淡出方向
默认值：关闭。仅在 **名称标签淡入淡出** 开启时可用。

如果启用，昵称标签在靠近车辆时是透明的，离车辆越远就越清晰。

如果禁用，昵称标签在靠近车辆时清晰可见，离车辆越远就越淡。
:::

### 玩家列表

::: details 显示玩家ID
默认值：开启。

如果启用，玩家列表会多出一列，显示每位玩家的 ID。这个 ID 对服务器管理人员很有用。

如果禁用，玩家列表只显示名称和延迟。
:::

::: details 高亮显示排队队列中的玩家
默认值：开启。

如果启用，有排队更改的玩家会在玩家列表中高亮显示。

如果禁用，不会高亮显示任何玩家。
:::

::: details 玩家列表左键操作
默认值：**事件队列**。

此设置决定在玩家列表中左键点击玩家名称时执行什么操作。可选项有：

- **事件队列**：加载该玩家已排队的更改。
- **切换摄像机至**：观战该玩家。
- **打开配置**：打开该玩家的论坛个人资料。
- **删除所有车辆**：在你的游戏中删除该玩家的所有车辆。
- **删除车辆队列**：把你已删除的该玩家的车辆重新放入队列。
- **复制昵称**：复制该玩家的名称。

右键点击名称时，始终会打开一个包含以上所有操作的菜单。
:::

## 玩家 {#players}

::: details 在车牌上显示玩家名称
默认值：开启。

如果启用，其他玩家车辆的车牌上会显示该玩家的名称。

如果禁用，BeamMP 不会更改车牌文字。
:::

:::: details 车辆靠近时逐渐淡出
默认值：关闭。

如果启用，其他玩家的车辆在靠近时会逐渐淡出。从 20 m 外开始它们完全可见，在你所在的位置则完全透明。此功能仅在显示昵称标签时有效。

如果禁用，无论距离多远，其他玩家的车辆都保持完全可见。

::: info
这只会改变车辆的外观，不会改变它的物理特性。它适用于关闭碰撞的情况。游戏自带的相关设置位于 **游戏设置** 选项中。
:::
::::

::: details 可用时使用简化车辆
默认值：关闭。

如果启用，其他玩家的车辆会被替换为 BeamNG.drive 中的简化交通版本（对于有简化版本的车辆）。这会降低碰撞和画面的精度，但能提升性能。

如果禁用，游戏会使用其他玩家所选的车辆模型。
:::

## 高级 {#advanced}

::: details 启用车辆位置平滑
默认值：关闭。

如果启用，BeamMP 会对连接不稳定的玩家的位置数据进行平滑处理。这样可以减少车辆瞬移和橡皮筋效应。

如果禁用，BeamMP 会在收到车辆位置时立即更新。
:::

:::: details 在控制台显示网络活动
默认值：关闭。

如果启用，BeamMP 的网络活动会显示在控制台中。

如果禁用，控制台中不会显示这些内容。

::: danger
控制台输出同样会被写入日志文件。启用此设置后，日志文件可能在几分钟内增长数百 MB。
:::
::::

:::: details 启动器端口
默认值：4444。

这是游戏与启动器通信所使用的端口。只有在 4444 端口无法使用时才需要修改。请把 `Launcher.cfg` 中的 `Port` 设为同一个数字。

::: tip
你输入的端口只是两个端口中的第一个。游戏还会使用紧随其后的下一个端口：如果设为 4444，那就是 4445。第一个端口传输核心网络数据包，第二个端口传输游戏网络数据包。
:::
::::

## 聊天窗口 {#the-chat-window}

当 **新聊天菜单** 开启时，聊天是一个带有自己设置的 ImGui 窗口。点击窗口标题栏中的齿轮图标即可打开这些设置。它们分为两个选项卡，每个选项卡都有 **Reset to default** 和 **Save** 按钮。这些设置保存在 `settings/BeamMP/chat.json` 中。

::: details General 选项卡
**Inactive fade**：默认开启。如果启用，窗口在你不使用时会淡出。

**Fade time**：默认 2.5 s，最小 0.1 s。窗口在淡出之前等待的时间。

**Fade when collapsed**：默认关闭。如果启用，窗口在折叠时也会淡出。

**Show on message**：默认开启。如果启用，有消息到达时窗口会重新出现。

**Keep active on Enter**：默认开启。如果启用，按下 `Enter` 后，光标会留在消息输入框中。
:::

::: details Theming 选项卡
设置窗口的颜色：**Window Background**、**Button Background**、**Button Hovered**、**Button Active**、**Text Color**、**Primary Color** 和 **Secondary Color**。
:::

控制设置中的 **Bring to Front** 和 **Toggle Chat** 按键操作，可以让窗口在淡出后重新出现，以及将其隐藏。
