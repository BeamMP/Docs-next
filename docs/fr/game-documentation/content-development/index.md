# Développement de contenu

Le contenu pour BeamNG.drive comprend les cartes, les objets, les véhicules, les applications UI et les mods Lua. Un mod que vous créez pour le jeu fonctionne aussi avec BeamMP, si le serveur que vous rejoignez l'utilise.

Nous n'avons pas de guides propres pour créer des cartes, des objets ou des véhicules. La documentation de BeamNG les couvre :

- [Modding](https://documentation.beamng.com/modding/) : la vue d'ensemble de tout ce que vous pouvez créer.
- [Vehicles](https://documentation.beamng.com/modding/vehicle/) : la création de véhicules.
- [The World Editor](https://documentation.beamng.com/world_editor/) : la construction et la modification de cartes.
- [UI](https://documentation.beamng.com/modding/ui/) : la création d'éléments d'interface.
- [Programming](https://documentation.beamng.com/modding/programming/) : Lua, extensions et débogage.

Sur ce site :

- [Applications UI (HTML)](/fr/game-documentation/programming/ui-apps-html-cef) explique comment créer une application UI.
- [Tutoriel de fenêtre ImGui](/fr/game-documentation/programming/imgui) explique comment créer une fenêtre ImGui de base.
- Pour mettre un mod sur un serveur BeamMP, consultez [Création de mods et de ressources](/fr/developers/mod-and-resource-creation) et [Sécurité des mods](/fr/players/mod-safety).
