# Defender / 防火墙排除项

本指南介绍如何在 Windows Defender 防火墙和防病毒软件中，为 BeamMP 启动器和服务器创建排除项。

在修改防火墙之前，如果你处于专用网络中，请先确保在 Windows 网络设置中把你的网络设置为**专用**。

::: danger 排除项存在风险
创建排除项，即表示你了解允许程序在你的电脑上运行、并向公众开放家庭网络端口所带来的风险。因此，你放弃就可能发生在你或你家人身上的任何及一切损失追究 BeamMP 责任的权利。

对于外部链接的服务或网站上的任何内容，我们概不负责。
:::

## 让启动器通过防火墙

1. 打开 **高级安全 Windows Defender 防火墙**。
2. 点击 **入站规则**。
3. 点击右上角的 **新建规则**。
4. 选择 **程序**，然后点击 **下一步**。
5. 选择 **此程序路径**，并输入 `BeamMP-Launcher.exe` 的完整路径。默认路径为 `%appdata%\BeamMP-Launcher\BeamMP-Launcher.exe`，不要加引号。
6. 选择 **允许连接**。
7. 保持已勾选的网络类型不变，然后点击 **下一步**。
8. 为规则起一个名称，例如“BeamMP-Launcher”，然后点击 **完成**。

## 让服务器通过防火墙

服务器需要一条针对程序的规则和一条针对其端口的规则。玩家会通过 TCP 和 UDP 连接到同一个端口号，所以端口需要为每种协议各建一条规则。

1. 按照上面的步骤为程序创建规则，但使用 `BeamMP-Server.exe` 的完整路径，也就是你下载后放置该文件的位置。将规则命名为“BeamMP-Server”。
2. 再次点击 **新建规则**。
3. 选择 **端口**，然后点击 **下一步**。
4. 选择 **TCP** 和 **特定本地端口**，并输入与 `ServerConfig.toml` 中 `Port` 相同的端口。默认端口是 `30814`。
5. 选择 **允许连接**，保持已勾选的网络类型不变，并为规则起一个名称，例如“BeamMP-Server TCP”。
6. 选择 **UDP**，重复步骤 2 到 5，并将规则命名为“BeamMP-Server UDP”。

防火墙规则在你保存后立即生效。之后请重启启动器或服务器。

## 添加防病毒排除项

这适用于启动器和服务器。

1. 打开 **Windows 安全中心** 应用。
2. 点击 **病毒和威胁防护**。
3. 在 **病毒和威胁防护设置** 下，点击 **管理设置**。
4. 向下滚动到 **排除项**，然后点击 **添加或删除排除项**。
5. 点击 **添加排除项**，选择 **文件**，然后选择 `BeamMP-Launcher.exe` 或 `BeamMP-Server.exe`。这样可以防止程序本身被扫描或被删除。
6. 再次点击 **添加排除项**，选择 **进程**，并输入同一个程序的完整路径。这样可以防止该程序所打开的文件被扫描。

排除项适用于实时保护。计划扫描或手动扫描仍然可能会扫描被排除的文件。
