# Erste Schritte

BeamMP bringt Multiplayer in BeamNG.drive. Dieser Bereich führt dich von der Installation bis zum Fahren auf einem Server mit anderen Spielern.

## Was du brauchst

- Eine legale, aktuelle Kopie von BeamNG.drive.
- Windows oder Linux. Unter Linux funktioniert der Launcher mit dem nativen BeamNG.drive und mit BeamNG.drive über Proton, und du erstellst ihn selbst. Linux ist eine sekundäre Plattform, daher sind einige Fehler zu erwarten. Für macOS gibt es keinen Launcher.
- Eine Internetverbindung, über die der Launcher `backend.beammp.com`, `auth.beammp.com` und `forum.beammp.com` per HTTPS erreichen kann.

::: warning
BeamMP funktioniert nicht mit raubkopierten oder veralteten Kopien von BeamNG.drive, und das Support-Team kann bei Problemen damit nicht helfen.
:::

## Die drei Schritte

1. [BeamMP installieren](/de/get-started/install-beammp): Lade den Installer herunter (Windows) oder erstelle den Launcher selbst (Linux).
2. [Dem ersten Server beitreten](/de/get-started/join-first-server): Starte den Launcher, öffne den Multiplayer und verbinde dich.
3. [Die Einstellungen für den ersten Start prüfen](/de/get-started/multiplayer-settings-quickstart): die wenigen Multiplayer-Einstellungen, die du vor deiner ersten Sitzung kennen solltest.

## Wenn etwas schiefgeht

- Die Seiten zur [Fehlerbehebung](/de/troubleshooting/) behandeln Launcher-Updates, Verbindungsprobleme und Fehlercodes.
- Die [Spieler-FAQ](/de/players/faq) beantwortet die häufigsten Fragen.
- Du kannst im [Forum](https://forum.beammp.com) oder auf dem [Discord-Server](https://discord.gg/beammp) nachfragen.
