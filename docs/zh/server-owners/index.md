# 服务器所有者

托管和维护 BeamMP 服务器所需的一切。

## 从这里开始

选择你的托管方式：

- **在家里，使用你自己的电脑。** 这是免费的。请按照[搭建服务器](/zh/server-owners/host-a-server)操作。家庭网络以外的玩家只有在你[转发端口](/zh/server-owners/port-forwarding)之后才能加入。
- **使用 VPS 或托管公司。** 这样更简单也更安全，而且无需更改路由器设置。请按照[在 VPS 上设置服务器](/zh/server-owners/setup-vps)操作。

## 维护你的服务器

- [服务器配置](/zh/server-owners/configuration)：`ServerConfig.toml` 的设置、服务器名称和标签，以及原版地图路径。
- [服务器维护](/zh/server-owners/maintenance)：日志文件和更新服务器。
- [服务器手册](/zh/server-owners/manual)：环境变量、Resources 文件夹、命令行参数和限制。

## 出问题时

- [检查 CGNAT](/zh/server-owners/cgnat)：为什么已经转发了端口却没有人能加入。
- [服务器错误代码](/zh/server-owners/error-codes)：启动器窗口中的错误代码是什么意思。
- [服务器常见问题](/zh/server-owners/faq)：常见问题和已知问题。
