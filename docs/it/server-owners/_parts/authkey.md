## Ottenere una AuthKey

La AuthKey, chiamata anche "chiave di autenticazione", è ciò che fa comparire un server **pubblico** nella lista dei server. È consigliata anche per i server privati.

- Hai a disposizione un numero limitato di chiavi. Una chiave funziona su un solo server alla volta, quindi non puoi usare la stessa chiave per due server.
- Puoi ottenere altre chiavi sostenendo il progetto. Vedi [Come ottengo l'early access?](/it/players/faq) nelle FAQ del giocatore.
- Per questo ti serve un account [Discord](https://discord.com), che serve a prevenire lo spam.

::: warning
Non condividere mai la tua AuthKey e non mostrarla a nessuno. Trattala come una password.
:::

1. Accedi al [Keymaster](https://keymaster.beammp.com) con Discord, poi clicca su **Keys** a sinistra dello schermo.

   ![La home page del Keymaster, con Keys nel menu a sinistra](../../assets/content/keymaster_homepage.png)

2. Clicca sul pulsante verde **+** in alto a destra.

   ![La pagina Keys con il pulsante verde con il segno più in alto a destra](../../assets/content/keymaster_new_key.png)

3. Compila il campo **Server Name** e clicca su **Create**. Questo è solo il nome della chiave, non il nome che il tuo server mostra nella lista dei server. Per esempio:

   ![Il modulo della nuova chiave con un nome del server inserito](../../assets/content/keymaster_server_name.png)

   La chiave apparirà più o meno così:

   ![La chiave completata nell'elenco delle chiavi](../../assets/content/keymaster_key_done.png)

4. Copia il testo del campo **Key** cliccando sull'icona degli appunti a destra della chiave. In questo esempio la chiave è `3173a2e-6az0-4542-a3p0-ddqq5ff95558`. Tienila a portata di mano per il passo successivo.

   ![L'icona degli appunti accanto alla chiave](../../assets/content/keymaster_copy_key.png)
