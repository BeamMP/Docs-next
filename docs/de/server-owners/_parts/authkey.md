## Einen AuthKey besorgen

Der AuthKey, auch „Authentifizierungsschlüssel“ genannt, sorgt dafür, dass ein **öffentlicher** Server in der Serverliste erscheint. Auch für private Server wird er empfohlen.

- Du hast nur eine begrenzte Anzahl an Schlüsseln. Ein Schlüssel funktioniert immer nur für einen Server gleichzeitig, du kannst also nicht zwei Server mit demselben Schlüssel betreiben.
- Weitere Schlüssel bekommst du, wenn du das Projekt unterstützt. Siehe [Wie bekomme ich Early Access?](/de/players/faq) in der Spieler-FAQ.
- Dafür brauchst du ein [Discord](https://discord.com)-Konto. Das verhindert Spam.

::: warning
Gib deinen AuthKey niemals weiter und zeige ihn niemandem. Behandle ihn wie ein Passwort.
:::

1. Melde dich mit Discord beim [Keymaster](https://keymaster.beammp.com) an und klicke dann links auf dem Bildschirm auf **Keys**.

   ![Die Startseite des Keymasters, mit Keys im Menü auf der linken Seite](../../assets/content/keymaster_homepage.png)

2. Klicke oben rechts auf die grüne **+**-Schaltfläche.

   ![Die Seite Keys mit der grünen Plus-Schaltfläche oben rechts](../../assets/content/keymaster_new_key.png)

3. Fülle das Feld **Server Name** aus und klicke auf **Create**. Das ist nur der Name des Schlüssels, nicht der Name, den dein Server in der Serverliste anzeigt. Zum Beispiel:

   ![Das Formular für einen neuen Schlüssel mit ausgefülltem Servernamen](../../assets/content/keymaster_server_name.png)

   Der Schlüssel sieht dann ungefähr so aus:

   ![Der fertige Schlüssel in der Liste der Schlüssel](../../assets/content/keymaster_key_done.png)

4. Kopiere den Text im Feld **Key**, indem du rechts neben dem Schlüssel auf das Zwischenablage-Symbol klickst. In diesem Beispiel lautet der Schlüssel `3173a2e-6az0-4542-a3p0-ddqq5ff95558`. Behalte ihn für den nächsten Schritt.

   ![Das Zwischenablage-Symbol neben dem Schlüssel](../../assets/content/keymaster_copy_key.png)
