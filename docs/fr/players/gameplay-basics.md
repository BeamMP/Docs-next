# Bases du gameplay

Cette page explique ce qui change dans BeamNG.drive lorsque vous jouez sur un serveur BeamMP. Les paramètres associés à chaque élément sont décrits dans [Paramètres multijoueurs](/fr/players/multiplayer-settings).

## La liste des joueurs

La liste des joueurs en jeu affiche le nom et le ping de chaque joueur. Vous pouvez aussi afficher l'ID de chaque joueur, ce qui est utile pour le staff du serveur. Cliquer sur le nom d'un joueur permet de le regarder en mode spectateur, ou de charger ses modifications en attente : vous choisissez dans les paramètres quel bouton de la souris fait quoi.

## Pseudos

Chaque joueur a un pseudo au-dessus de son véhicule, qui peut afficher une étiquette de rôle. Vous pouvez masquer les pseudos, afficher la distance qui vous sépare de chaque joueur et les faire apparaître ou disparaître progressivement selon la distance.

## Chat

Le chat s'affiche soit dans une fenêtre que vous pouvez sortir du jeu (le nouveau menu de chat), soit dans l'application d'interface (UI app).

## Véhicules des autres joueurs

- Les véhicules des joueurs apparaissent dans votre jeu, et leurs modifications de pièces vous sont synchronisées. Vous pouvez envoyer vos propres modifications de pièces aux autres avec le bouton de synchronisation des pièces dans le sélecteur de pièces, ou les faire envoyer automatiquement.
- Appuyez sur `Tab` pour passer d'un véhicule à l'autre. Vous pouvez ignorer les véhicules des autres joueurs.
- Un véhicule qui n'est pas encore apparu chez vous s'affiche sous la forme d'une sphère colorée, appelée blob.
- Pour protéger votre création, activez la protection contre le clonage de configuration : les autres joueurs ne pourront pas enregistrer la configuration de votre véhicule.

## La file d'événements

Lorsqu'un autre joueur fait apparaître ou modifie un véhicule, votre jeu peut mettre la modification en file d'attente au lieu de la charger immédiatement, afin qu'un chargement n'interrompe pas votre conduite. Les modifications en attente se chargent lorsque vous cliquez sur le bouton **Events** en haut de l'écran, lorsque vous cliquez sur le nom du joueur, ou automatiquement lorsque vous roulez lentement depuis assez longtemps. Consultez [les paramètres de la file d'événements](/fr/players/multiplayer-settings#event-queue).

## Serveurs avec mods

Lorsque vous vous connectez à un serveur qui utilise des mods, BeamMP affiche d'abord un avertissement de sécurité sur les mods. Lisez [Sécurité des mods](/fr/players/mod-safety) avant de l'accepter.
