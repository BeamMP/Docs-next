# Risoluzione problemi

Trova qui sotto il tuo problema. Se nessuno corrisponde, consulta le [FAQ del gioco](/it/players/game-faq) oppure chiedi sul [forum](https://forum.beammp.com) o sul [server Discord](https://discord.gg/beammp).

## Il Launcher non si avvia o non si aggiorna

- [Problemi di aggiornamento del Launcher](/it/troubleshooting/launcher-update): il Launcher non riesce ad aggiornarsi o mostra una schermata vuota. Aggiornalo a mano su Windows o Linux.
- [Codici di errore](/it/troubleshooting/error-codes): cosa significano i messaggi nella finestra del Launcher, anche quando non riesce a trovare o ad avviare il gioco.

## Non riesco a connettermi

- [Problemi di connessione / rete](/it/troubleshooting/connection-networking): trova l'indirizzo IP del tuo server, prova la tua porta, verifica la presenza di CGNAT e consulta le porte usate dal Launcher.
- [Cambiare la porta del Launcher](/it/troubleshooting/launcher-port): il Launcher non si connette al gioco.
- [Esclusioni Defender / Firewall](/it/troubleshooting/defender-exclusions): consenti al Launcher e al server di passare attraverso la sicurezza di Windows.

## Gestisco un server

Consulta i [codici di errore del server](/it/server-owners/error-codes) e le [FAQ del server](/it/server-owners/faq).
