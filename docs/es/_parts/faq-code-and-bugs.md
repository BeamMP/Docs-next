### ¿Dónde puedo encontrar el código?

Todo el código fuente está en [GitHub](https://github.com/BeamMP). El código está sujeto a nuestros [Términos de uso](https://forum.beammp.com/t/terms-of-use-v1-0/43) y a estas licencias:

| Código | Licencia |
|---|---|
| Servidor | [LICENSE](https://github.com/BeamMP/BeamMP-Server/blob/master/LICENSE) |
| Launcher | [LICENSE](https://github.com/BeamMP/BeamMP-Launcher/blob/master/LICENSE) |
| Lua del cliente | [LICENSE](https://github.com/BeamMP/BeamMP/blob/development/LICENSE) |

### He encontrado un error o un exploit. ¿Qué debo hacer?

Si es un problema del código y sabes usar GitHub, abre una "Issue" en el repositorio correspondiente de nuestro [GitHub](https://github.com/BeamMP). Usamos un flujo de trabajo basado en issues, así que, aunque ya tengas una solución, abre primero una Issue y después una "Pull Request" que la resuelva. Encontrarás más información sobre cómo contribuir en la [guía de contribución](https://github.com/BeamMP/BeamMP/blob/development/CONTRIBUTING.md).

Si no tienes una cuenta de GitHub, o no sabes usarlo, puedes ponerte en contacto de otra forma:

- Si no es algo delicado, publícalo en el [foro de BeamMP](https://forum.beammp.com) o infórmalo en el [servidor de Discord](https://discord.gg/beammp).
- Si es delicado, infórmalo directamente a un miembro del personal en [Discord](https://discord.gg/beammp).
