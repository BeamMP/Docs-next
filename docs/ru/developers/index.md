# Разработчикам

BeamMP состоит из трёх частей, и для каждой из них можно писать код. В этом разделе объясняется, как они связаны между собой и с чего начать.

## Три части

- **Мод** загружается BeamNG.drive, как любой другой мод транспорта или интерфейса. Он устанавливает локальное соединение с лаунчером и показывает интерфейс мультиплеера. В основном он написан на Lua, а для интерфейса используются JavaScript, HTML и CSS. Его репозиторий: [BeamMP/BeamMP](https://github.com/BeamMP/BeamMP).
- **Лаунчер** постоянно поддерживает соединение с модом, подключается к выбранному вами серверу и выполняет вход через бэкенд BeamMP. Он написан на C++, предварительно собирается командой BeamMP и находится по адресу [BeamMP/BeamMP-Launcher](https://github.com/BeamMP/BeamMP-Launcher).
- **Сервер** объединяет один или несколько лаунчеров и отправляет бэкенду BeamMP «хартбиты» (heartbeats) со своим IP-адресом, портом, версией, числом игроков и другими данными. Он также запускает серверные Lua-плагины. Он написан на C++, предварительно собирается командой BeamMP для нескольких операционных систем и архитектур процессоров и находится по адресу [BeamMP/BeamMP-Server](https://github.com/BeamMP/BeamMP-Server).
