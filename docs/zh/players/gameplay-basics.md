# 玩法基础

本页介绍在 BeamMP 服务器上游玩时，BeamNG.drive 有哪些不同之处。每一部分背后的设置见[多人模式设置](/zh/players/multiplayer-settings)。

## 玩家列表

游戏内的玩家列表会显示每位玩家的名称和延迟。你还可以显示每位玩家的 ID，这对服务器管理人员很有用。点击玩家名称可以观战该玩家，或加载他们已排队的更改：哪个鼠标按键执行哪个操作，由你在设置中决定。

## 昵称标签

每位玩家的车辆上方都有一个昵称标签，标签上还可以带有角色标签。你可以隐藏昵称标签、显示与每位玩家的距离，也可以让昵称标签随距离淡入或淡出。

## 聊天

聊天要么显示在一个可以拖出游戏的窗口中（新聊天菜单），要么显示在 UI 应用程序中。

## 其他玩家的车辆

- 其他玩家的车辆会出现在你的游戏中，他们对零件的更改也会同步给你。你可以用零件选择器中的零件同步按钮，把自己对零件的更改发送给其他人，也可以让它们自动发送。
- 按 `Tab` 在车辆之间切换。你可以跳过其他玩家的车辆。
- 尚未为你刷出的车辆会显示为一个彩色的占位球，称为斑点（blob）。
- 为保护你的作品，请开启配置克隆保护，这样其他玩家就无法保存你的车辆配置。

## 事件队列 {#event-queue}

当其他玩家刷出或编辑车辆时，你的游戏可以把这些更改放入队列，而不是立即加载，这样加载就不会打断你的驾驶。排队的更改会在你点击屏幕顶部的 **Events** 按钮、点击该玩家的名称，或是在你低速行驶足够长时间后自动加载。请参阅[事件队列设置](/zh/players/multiplayer-settings#event-queue)。

## 带有模组的服务器

当你连接到带有模组的服务器时，BeamMP 会先显示模组安全警告。接受之前，请先阅读[模组安全](/zh/players/mod-safety)。
