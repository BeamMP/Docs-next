# Изменение порта лаунчера

Лаунчер не подключается к игре? Это руководство объясняет, как вручную изменить порт лаунчера. Порт должен совпадать в игре и в лаунчере.

Порт по умолчанию — `4444`. Лаунчер использует этот порт и следующий за ним, `4445`, на вашем собственном компьютере. Оба работают по TCP, и оба должны быть свободны. Если один из них использует другая программа, лаунчер показывает `bind failed with error`, как описано в разделе [Коды ошибок](/ru/troubleshooting/error-codes).

1. Запустите BeamNG.drive.
2. В главном меню выберите **Настройки**, затем вкладку **BeamMP**.
3. Откройте группу **Расширенные параметры**.
4. В поле **Launcher port** замените число на другое, например на `4567`.
5. Закройте BeamNG.drive.
6. Щёлкните правой кнопкой мыши по ярлыку лаунчера BeamMP и выберите **Открыть расположение файла** (Open file location).
7. Откройте `Launcher.cfg` в текстовом редакторе.
8. Замените число в `"Port": 4444,` на порт, который вы задали в игре, в этом примере `4567`.
9. Сохраните файл и закройте редактор. Файл должен остаться корректным JSON: если лаунчер не сможет его прочитать, он покажет `Config failed to parse make sure it's valid JSON!` и закроется.
10. Запустите лаунчер.

Если подключение всё равно не устанавливается, попробуйте другой порт. Используйте число от 1024 до 65534, потому что лаунчер использует ещё и следующее за ним число.

::: tip
Порт можно задать и без редактирования `Launcher.cfg`. Запустите лаунчер с параметром `--port 4567`. Параметр командной строки заменяет значение из `Launcher.cfg`. Остальные параметры описаны на странице [Настройка среды разработки](/ru/developers/dev-environment-setup#turn-on-dev-mode-in-the-launcher).
:::
