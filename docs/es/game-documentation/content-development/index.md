# Desarrollo de contenido

El contenido para BeamNG.drive son mapas, objetos, vehículos, aplicaciones de IU y mods Lua. Un mod que crees para el juego también funciona con BeamMP, si el servidor al que te unes lo tiene.

No tenemos guías propias para crear mapas, objetos ni vehículos. La documentación de BeamNG los cubre:

- [Modding](https://documentation.beamng.com/modding/): la visión general de todo lo que puedes crear.
- [Vehículos](https://documentation.beamng.com/modding/vehicle/): creación de vehículos.
- [El editor de mundo](https://documentation.beamng.com/world_editor/): construcción y edición de mapas.
- [IU](https://documentation.beamng.com/modding/ui/): creación de elementos de IU.
- [Programación](https://documentation.beamng.com/modding/programming/): Lua, extensiones y depuración.

En este sitio:

- [Aplicaciones de IU (HTML)](/es/game-documentation/programming/ui-apps-html-cef) muestra cómo crear una aplicación de IU.
- [Tutorial de ventana ImGui](/es/game-documentation/programming/imgui) muestra cómo crear una ventana ImGui básica.
- Para poner un mod en un servidor de BeamMP, consulta [Creación de Mods y Recursos](/es/developers/mod-and-resource-creation) y [Seguridad de mods](/es/players/mod-safety).
