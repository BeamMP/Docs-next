### J'ai trouvé un bug ou une faille. Que dois-je faire ?

S'il s'agit d'un problème de code et que vous savez utiliser GitHub, ouvrez une « Issue » dans le bon dépôt sur notre [GitHub](https://github.com/BeamMP). Nous travaillons à partir des issues : même si vous avez déjà un correctif, ouvrez d'abord une Issue, puis une « Pull Request » qui la résout. Pour en savoir plus sur la contribution, consultez le [guide de contribution](https://github.com/BeamMP/BeamMP/blob/development/CONTRIBUTING.md).

Si vous n'avez pas de compte GitHub, ou si vous ne savez pas utiliser GitHub, vous pouvez nous contacter autrement :

- Si le sujet n'est pas sensible, publiez un message sur le [forum BeamMP](https://forum.beammp.com) ou signalez-le sur le [serveur Discord](https://discord.gg/beammp).
- S'il est sensible, signalez-le directement à un membre du staff sur [Discord](https://discord.gg/beammp).
