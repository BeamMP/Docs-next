# 首次多人模式设置

BeamMP 有自己的多人模式设置。你不需要修改其中任何一项就能游玩。下面这些是第一次游玩时值得了解的设置。每一项设置的详细说明都在[多人模式设置](/zh/players/multiplayer-settings)中。

## 查看设置

在 BeamNG.drive 中，点击 **选项**，然后选择 **BeamMP**。所有设置都在这一页，并按分组排列。没有用来显示隐藏设置的开关。

## 你可能想要修改的设置

| 设置 | 作用 | 何时修改 |
|---|---|---|
| **新聊天菜单** | 将游戏内聊天显示在一个可以拖出游戏的窗口中，例如拖到另一台显示器上 | 你想把聊天放在第二块屏幕上 |
| **启用车辆位置平滑** | 对连接不稳定的玩家的位置数据进行平滑处理，从而减少车辆瞬移 | 有玩家的延迟较高，或你的连接经常丢包 |
| **可用时使用简化车辆** | 在有简化版本时，用 BeamNG.drive 的简化交通版本替换其他玩家的车辆 | 在玩家很多的服务器上性能不佳 |
| **跳过模组安全警告弹窗** | 隐藏连接到带有模组的服务器时显示的警告 | 你经常连接同样的服务器，并且信任它们 |
| **隐藏玩家的名称标签** | 不再绘制昵称标签 | 昵称标签碍事 |
| **启用玩家车辆更新/编辑排队处理** | 将其他玩家的车辆刷出和编辑放入队列，而不是立即加载 | 你希望由自己决定车辆何时出现；参见[事件队列](/zh/players/multiplayer-settings#event-queue) |
| **启用配置克隆保护** | 阻止其他玩家克隆或保存你的车辆 | 你不希望别人复制你的作品 |

## 建议保持默认的设置

- **在控制台显示网络活动**会把所有内容写入日志文件，几分钟内日志就可能增长数百兆字节。
- **启动器端口** 只有在无法使用 4444 端口时才需要修改。如果你修改了它，请把 `Launcher.cfg` 中的 `Port` 设为同一个数字。参见[更改启动器端口](/zh/troubleshooting/launcher-port)。
