# Documentación del juego

BeamMP se ejecuta dentro de BeamNG.drive, así que gran parte de lo que escribes para BeamMP es en realidad código de BeamNG.drive. Esta sección reúne guías y fragmentos para ese código. La [documentación](https://documentation.beamng.com/) de BeamNG es la referencia completa.

Para las funciones y eventos propios de BeamMP, consulta las [referencias de scripting](/es/developers/beammp-scripting/).

## Guías

- [Desarrollo de contenido](/es/game-documentation/content-development/): dónde aprender a crear mapas, objetos y vehículos.
- [Aplicaciones de IU (HTML)](/es/game-documentation/programming/ui-apps-html-cef): crea una aplicación que se muestre en la pantalla del juego.
- [Tutorial de ventana ImGui](/es/game-documentation/programming/imgui): crea una ventana ImGui básica.
