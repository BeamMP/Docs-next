# 内容开发

BeamNG.drive 的内容包括地图、道具、车辆、图形界面应用程序和 Lua 模组。只要你加入的服务器也装有该模组，你为游戏制作的模组在 BeamMP 中同样可以使用。

我们没有自己的地图、道具或车辆制作指南。这些内容请参阅 BeamNG 的文档：

- [Modding](https://documentation.beamng.com/modding/)：可以制作的所有内容的概览。
- [Vehicles](https://documentation.beamng.com/modding/vehicle/)：制作车辆。
- [The World Editor](https://documentation.beamng.com/world_editor/)：构建和编辑地图。
- [UI](https://documentation.beamng.com/modding/ui/)：制作界面元素。
- [Programming](https://documentation.beamng.com/modding/programming/)：Lua、扩展和调试。

本站内：

- [图形界面应用程序（HTML）](/zh/game-documentation/programming/ui-apps-html-cef)介绍如何制作图形界面应用程序。
- [ImGui 窗口教程](/zh/game-documentation/programming/imgui)介绍如何创建一个基础的 ImGui 窗口。
- 如需把模组放到 BeamMP 服务器上，请参阅[模组与资源制作](/zh/developers/mod-and-resource-creation)和[模组安全](/zh/players/mod-safety)。
