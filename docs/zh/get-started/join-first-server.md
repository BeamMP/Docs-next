# 加入你的第一个服务器

你已经[安装了 BeamMP](/zh/get-started/install-beammp)。现在启动启动器并连接到服务器。

## 启动多人模式

1. 启动 BeamMP 启动器。会弹出一个终端窗口，随后不久标准的 BeamNG 启动程序也会启动。请勿关闭终端窗口。
2. 在 BeamNG.drive 主菜单中点击 **Repository**，并确认 `multiplayerbeammp` 是唯一启用的模组。
3. 返回主菜单，点击 **More…**，然后点击 **Multiplayer**。
4. 登录，或以访客身份游玩。并非所有服务器都允许访客。你可以在[论坛](https://forum.beammp.com)上创建账号，然后用同样的信息登录 BeamMP。
5. 选择一个服务器，然后点击 **Connect**。

::: info 加入可能需要一些时间
当你加载到一张已经刷出了大量车辆的地图时，加入所需的时间可能比你预期的更长。
:::

## 如果无法连接

- **没有 Multiplayer 按钮。** 请确认 BeamMP 模组存在，并已在 **Mod Manager** 中启用，然后按 `Ctrl` + `L`。
- **开启了 VPN。** 任何类型的 VPN 都可能导致连接问题。请将其关闭后重试。
- **启动器显示错误。** 请在[错误代码](/zh/troubleshooting/error-codes)或[论坛常见问题](https://forum.beammp.com/c/faq/35)中查找。
- **在 Linux 上只能连接一次。** 原生 Linux 版启动器目前每次启动只能连接一个服务器。断开连接后，请重启启动器。你可以在不关闭游戏的情况下做到这一点。

如需更多帮助，请参阅[故障排除](/zh/troubleshooting/)，或在[论坛](https://forum.beammp.com)或 [Discord 服务器](https://discord.gg/beammp)上提问。
