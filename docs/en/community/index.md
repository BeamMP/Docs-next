# Community

BeamMP is a community of players, server owners and developers. This is where to find us.

## Talk to us

- [Forum](https://forum.beammp.com): questions, guides, server announcements and support threads.
- [Discord](https://discord.gg/beammp): chat, the `#support` channel and server support tickets.

## Support the project

[Patreon](https://www.patreon.com/c/BeamMP) supporters get early access and extra server keys. See the [Player FAQ](/en/players/faq) for how it works.
